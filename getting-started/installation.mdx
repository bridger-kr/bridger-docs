Bridger는 별도 패키지 설치 없이 호스팅 Gateway로 사용할 수 있습니다.
클라이언트에서는 API 키와 Gateway URL만 설정하면 됩니다.

## API 키

[portal.bridger.kr](https://portal.bridger.kr)에서 계정을 만들고 **Settings → API Keys**에서 키를 발급받습니다.

```bash
export BRIDGER_API_KEY="dk_live_..."
```

## Gateway URL

```bash
export BRIDGER_GATEWAY_URL="https://mcp.bridger.kr/mcp"
```

## 연결 확인

```bash
curl -X POST "$BRIDGER_GATEWAY_URL" \
  -H "x-api-key: $BRIDGER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
