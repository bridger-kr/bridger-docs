title: "빠른 시작"
description: "로그인하고 Claude · ChatGPT에 브릿저를 연결해 첫 질문까지 — 개발 도구 없이 3단계."
---

브릿저(Bridger)는 Claude · ChatGPT 같은 AI 앱에서 한국 공공데이터를 바로 물어볼 수 있게 해주는
커넥터입니다. 설치할 프로그램도, 미리 발급할 API 키도 없습니다.

## 3단계면 끝납니다

<Steps>
  <Step title="브릿저 로그인">
    [portal.bridger.kr](https://portal.bridger.kr)을 열고 **Google** 또는 **GitHub** 계정으로
    로그인합니다. 별도 회원가입 절차 없이 소셜 계정으로 바로 시작됩니다.
  </Step>
  <Step title="AI 앱에 브릿저 연결">
    사용하는 AI 앱의 설정 화면에서 브릿저를 커넥터로 추가합니다. 서버 주소는 두 앱 모두
    `https://mcp.bridger.kr/mcp` 하나입니다.

    - **Claude (웹 · 데스크톱):** 설정(Settings) → 커넥터(Connectors) →
      **사용자 지정 커넥터 추가(Add custom connector)** → 이름 `브릿저`, 서버 주소 붙여넣기 →
      **연결(Connect)**. 화면에 맞춘 단계별 안내는 [Claude 연결 가이드](/guides/claude)에 있습니다.
    - **ChatGPT:** 설정(Settings) → 앱(Apps) → **개발자 모드(Developer mode)** 켜기 →
      만들기(Create) → 이름 `브릿저`, MCP 서버 주소 붙여넣기 → **도구 스캔(Scan tools)**.
      계정 플랜에 따라 개발자 모드가 보이지 않을 수 있습니다. 자세한 내용은
      [ChatGPT 연결 가이드](/guides/chatgpt)에 있습니다.

    연결(Connect)을 누르면 브라우저에서 브릿저 로그인과 권한 동의(OAuth) 화면이 열립니다.
    1단계와 같은 Google · GitHub 계정으로 로그인하고 **승인(Allow)** 을 누르면 완료입니다.
  </Step>
  <Step title="첫 질문">
    새 대화에서 브릿저 커넥터를 켠 뒤 그대로 물어보세요. 아래 질문은 브릿저 카탈로그의
    공공데이터를 사용합니다.

    {/* example-api: environment/air-quality-realtime */}
    - "서울 중구 미세먼지 상태 알려줘" — 대기오염 실시간 측정
    {/* example-api: weather/village-forecast */}
    - "오늘 서울 날씨 어때?" — 기상청 동네예보
    {/* example-api: realestate/apt-trade */}
    - "반포동 아파트 실거래가 알려줘" — 국토교통부 아파트 매매 실거래가
    {/* example-api: economy/stock-price */}
    - "삼성전자 주가 알려줘" — 금융위원회 주식시세정보
  </Step>
</Steps>

## 막혔을 때

<AccordionGroup>
  <Accordion title="로그인·승인 창이 열리지 않아요">
    브라우저 팝업 차단을 해제하고 다시 **연결(Connect)** 을 눌러 보세요.
  </Accordion>
  <Accordion title="질문에 답이 없거나 키를 요구해요">
    일부 공공데이터는 제공기관(data.go.kr)의 **서비스키**가 필요합니다.
    포털의 **정부 API** 메뉴에서 사용할 API를 열면 기본키로 호출 가능한지, 내 서비스키가
    필요한지 바로 확인할 수 있습니다. 등록 방법은 [API 키 가이드](/guides/api-keys)를 참고하세요.
  </Accordion>
  <Accordion title="ChatGPT에서 개발자 모드가 보이지 않아요">
    계정 플랜·워크스페이스 권한에 따라 제한됩니다. 관리자에게 앱 사용 권한을 요청하거나,
    개발자 모드 없이 되는 [Claude 연결 가이드](/guides/claude)를 먼저 따라 해 보세요.
  </Accordion>
</AccordionGroup>
