datari를 사용하는 가장 빠른 길은 **datari 호스팅 Gateway**(`mcp.datari.kr`)에 API 키만
가지고 붙는 것입니다. CLI나 Gateway를 직접 실행할 필요 없이 즉시 시작합니다.

## 1. API 키 발급

[admin.datari.kr](https://admin.datari.kr)에서 무료 계정을 만들고 **Settings → API Keys**에서
키를 발급받습니다. 자세한 내용은 [구독 가이드](/guides/subscribe)를 참고하세요.

```bash
export DATARI_API_KEY="dat_live_..."
```

## 2. 사용 가능한 도구 확인

JSON-RPC `tools/list`로 datari에 등록된 모든 도구 목록을 조회합니다.

```bash
curl -X POST https://mcp.datari.kr/mcp \
  -H "x-api-key: $DATARI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

## 3. 첫 도구 호출

도구 한 개를 실제로 실행해 봅니다. 아래는 기상청 초단기예보 호출 예시입니다.

```bash
curl -X POST https://mcp.datari.kr/mcp \
  -H "x-api-key: $DATARI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 2,
    "method": "tools/call",
    "params": {
      "name": "weather_forecast_short",
      "arguments": {
        "city": "서울",
        "district": "강남구"
      }
    }
  }'
```
