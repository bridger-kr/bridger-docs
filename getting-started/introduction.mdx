---
title: "Bridger란?"
description: "공공데이터 API와 BYOAPI를 AI가 MCP 표준으로 바로 사용할 수 있게 잇는 다리."
---

Bridger는 **데이터** + **다리**의 의미를 담은 공공데이터 운영 게이트웨이입니다.
현재 {{catalogTotal}}종의 공공데이터 API를 MCP 도구로 제공합니다.
({{catalogTotal}}은 공개 카탈로그에 등록된 공공데이터 API 수이며, 프리셋이 노출하는 MCP 도구 수와는 다릅니다.)
공공데이터 API의 인증·파싱·에러 처리를 대신하고, AI가 [Model Context Protocol (MCP)](/concepts/mcp) 표준으로
바로 사용할 수 있도록 도구로 변환합니다. OpenAPI 스펙이 있는 REST API를 등록하면 AI 도구가 됩니다.
