# DATA BRIDGE docs

Mintlify documentation for DATA BRIDGE, published at `docs.datari.kr`.

> Private internal documentation deployment repository.

## Layout

| Path | Purpose |
| --- | --- |
| `<section>/` | Mintlify pages |
| `docs.json` | navigation and theme configuration |
| `logo/` | brand assets |
| `nginx.conf` | static-server config used by the production image |
| `scripts/` | content generation helpers |

## Local dev

```bash
npm install
npm run dev
```
