<Warning>충전소 데이터는 수원시 목록만 제공됩니다. 거리순 추천, 실시간 충전 가능 여부, 전국 커버리지는 확인해 주지 않습니다.</Warning>

## 1. 이런 질문으로 시작

한국 지역의 환경 정보를 반복 확인하는 담당자가 야외 일정을 준비할 때 이렇게 물어봅니다.

- "수원 영통구 오늘 날씨 알려줘."
- "수원시 현 시간 대기질 상태 알려줘."
- "수원시 전기차 충전소 목록 알려줘."

여러 지역과 시점을 함께 묻는 질문("수원 지역 오늘 날씨·대기질·전기차 충전소 알려줘")도
작동하며, 앱(Claude · ChatGPT)은 지역 → 날씨 → 대기질 → 충전소 순으로 도구를 나눠 호출합니다.

## 2. 어떤 도구가 사용되는가

질문에 따라 아래 도구가 호출됩니다. 프리셋·도구 목록은 각 카탈로그에 있습니다.

| 구성요소 | 프리셋 · 도구 | 참고 |
| --- | --- | --- |
| 위치 | `resolve_location` | 지역명·좌표를 기상 격자·행정 코드로 정규화. 대기 측정소까지 자동으로 골라 주지는 않습니다. [지역 입력 방식](/concepts/korean-data) |
| 날씨 | [기상 카탈로그](/presets/weather)의 `weather/village-forecast` · `getVillageForecast` | 동네예보. 격자 좌표(nx·ny)와 발표일자·발표시각을 함께 다룹니다 |
| 대기질 | [환경 카탈로그](/presets/environment)의 `environment/air-quality-realtime` · `getAirQualityRealtimeByStation` | 측정소 단위 조회 |
| 충전소 | [교통 카탈로그](/presets/transportation)의 `transportation/ev-charging` · `getEvCharging` | **수원시** 데이터만 |

동명 지역이나 잘못된 좌표는 대상을 특정하지 않으면 답을 얻을 수 없습니다.
개발 환경에서는 [첫 도구 호출](/getting-started/first-tool)처럼 `tools/list` ·
`tools/call`로 직접 호출할 수 있습니다.

## 3. 결과를 어떻게 읽는가

| 구성요소 | 읽는 법 |
| --- | --- |
| 날씨 | 예보입니다. 발표 시각(발표 기준)과 예보 대상 시점을 따로 구분해 읽고, 관측값과 혼동하지 않습니다 |
| 대기질 | 측정소 단위 값입니다. 측정 시각과 측정소를 확인하고, 한 측정소 값을 지역 전체 상황으로 일반화하지 않습니다. 결측이 있으면 그 부분만 비어 있습니다 |
| 충전소 | 수원시 충전소 등록 목록입니다. 주소·좌표는 있지만 "지금 사용 가능한 충전기"나 거리순 정렬을 의미하지 않습니다 — 근처 여부는 별도 좌표·거리 계산이 필요합니다 |
| 위치 | 정규화된 행정 코드·기상 격자입니다. 상세 주소 검증 결과가 아닙니다 |

여러 구성요소를 한 번에 물었을 때 일부만 답해도 누락 이유를 확인하면 됩니다:
수원 외 지역 충전소, 결측 대기값, 아직 발표되지 않은 예보 시각 등으로 사유가 나뉩니다.
남는 부분은 해당 도구로 따로 확인하세요.

## 이 작업의 경계

- 각 데이터의 제공기관·키 요구사항은 카탈로그 표([기상·기상청](https://www.data.go.kr/data/15084084/openapi.do), [대기질·에어코리아](https://www.data.go.kr/data/15073861/openapi.do), [충전소·수원시](https://www.data.go.kr/data/15144026/openapi.do))에서 확인하고, 키 문제는 [API 키 가이드](/guides/api-keys)를 참고합니다.
- 관측·측정 시각과 예보 발표 시각은 제공기관이 정한 시각이며, HTTP 응답 시각과 다를 수 있습니다.
- 추천·예약·의학적 판단·이동 경로 최적화는 범위 밖입니다. 응답은 원천 데이터를 정리해 보여 줄 뿐입니다.
