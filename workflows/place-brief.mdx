<Warning>실제 실행 결과가 아닌 작업 계약입니다. 전국 충전소 커버리지, 실시간 데이터, 현재 충전 가능 여부나 정확한 거리순 결과를 보장하지 않습니다.</Warning>

## 대상과 입력

한국 지역의 환경 정보를 반복 확인하는 제품팀·자동화 파트너를 위한 작업입니다.
한국 지역명 또는 좌표, 기상 예보 발행일/시각, 예보 대상 시점, 확인한 대기 측정소 이름을 입력으로 사용합니다.
위치는 `resolve_location`으로 기상 격자/행정 코드에 정규화할 수 있지만 대기 측정소를 자동으로 확정하지 않습니다.
잘못된 좌표·동명 지역은 재입력 대상으로 남깁니다.

네 구성요소(위치·날씨·대기질·충전소)를 모두 요청하는 계약입니다.
채택 가능한 결과는 서로 다른 기준 시각·공간 범위·누락을 표시한 브리핑을 담당자가 실제 업무에 사용했다고 확인한 경우입니다.
추천·안전 보장·예약·의학적 판단이나 이동 경로 최적화는 범위 밖입니다.
원문 주소·좌표·질의·키는 optional 분석에 보내지 않습니다.

## 기존 가이드와 도구

1. [AI 연결](/guides/claude)과 [첫 도구 실행](/getting-started/first-tool)의 인증·활성화 경로를 재사용합니다.
2. `resolve_location`의 지원 지역을 확인하고 애매한 지명은 사용자가 명확하게 지정합니다.
3. [기상 프리셋](/presets/weather)의 `weather/village-forecast`, `getVillageForecast`와 기존 날씨 위젯을 사용합니다. 예보와 관측을 구분합니다.
4. [환경 프리셋](/presets/environment)의 `environment/air-quality-realtime`, `getAirQualityRealtimeByStation`에서 측정소와 측정 기준 시각을 함께 읽습니다.
5. [교통 프리셋](/presets/transportation)의 `transportation/ev-charging`, `getEvCharging`은 **수원시** 데이터입니다. 타 지역은 `unsupported_region`으로 표시합니다.
6. 각 응답의 기준 시각과 누락을 보존한 뒤 사람이 검토합니다. 결과 조회와 작업 채택은 별개입니다.

충전소 목록의 좌표·주소가 있어도 원본 조회가 거리순 검색이나 빈 충전기 확인을 보장하지 않습니다.
근처 여부는 별도 검증된 좌표·거리 계산이 필요한데 이 예시에서는 실행하지 않았습니다.

## 출처·시점·권한·비용

저장소 메타데이터 검토일: 2026-10-10. 기관 live smoke는 수행하지 않았습니다.

| 구성요소 | 출처·지원 범위 | `asOf` 의미 |
| --- | --- | --- |
| 위치 | [임베디드 지역/격자 도구](https://github.com/bridger-kr/bridger-api/blob/86017b0666c9e8578ec4a8c4260b007dea92219f/internal/mcpedge/resolve_location.go). 상세 주소 검증 아님 | 데이터 버전 + 계산 시각; 기관 관측 시각 아님 |
| 날씨 | [기상청 단기예보](https://www.data.go.kr/data/15084084/openapi.do). 기상 격자·발행 시점·예보 대상 시점 필요 | 발행과 예보 시점을 별도 표시 |
| 대기질 | [에어코리아](https://www.data.go.kr/data/15073861/openapi.do). 측정소 단위; 결측 가능 | 측정 시각, 지역 전체 값으로 일반화하지 않음 |
| 충전소 | [수원시 목록](https://www.data.go.kr/data/15144026/openapi.do). 저장소에 공식 첨부 문서 unavailable 기록이 있음 | 원본 갱신/상태 시각. 불명은 `missing_asof` |

키·기관 신청/쿼터·이용조건·재배포 범위를 담당자가 확인해야 합니다.
내 인증키 또는 관리 키의 사용 가능 여부와 브릿저 요금·지원 범위도 실행 전에 확인합니다.
여기에는 기관 권리 승인이나 무료/무제한 보장 증거가 없습니다.
최신성 허용 기준은 구성요소와 용도별로 합의하고 문서화해야 하며, HTTP 응답 시각을 측정 시각으로 바꾸지 않습니다.

## 결과 계약

이 페이지와 합성 fixture는 제안된 정규화 envelope입니다. 현재 MCP 응답 스키마나 커넥터 동작을 바꾸지 않습니다.
모든 요청 구성요소는 `source`, `asOf`, `unavailable`을 포함합니다.

| 결과 | 의미 |
| --- | --- |
| `success` | 네 구성요소 모두 사용 가능한 행과 확인된 기준 시각이 있음. 사람이 채택하기 전에는 `adopted` 아님 |
| `partial` | 사용 가능한 일부가 있으나 다른 부분이 비거나 누락됨. 수원 외 충전소, 결측 측정값, 오래된 예보 등의 사유를 표시 |
| `empty` | 사용 가능한 행은 없고 최소 하나의 유효한 빈 응답이 있음. 다른 오류도 숨기지 않음 |
| `error` | 모든 구성요소가 키·입력·시간 초과·기관 장애 등으로 사용할 수 없음 |

지원되지 않는 지역과 최신성 초과는 성공 행으로 꾸미지 않습니다.
기준 시각이 없는 응답은 현재 시각을 삽입하지 않고 해당 부분을 `missing_asof`로 남깁니다.
부분 결과를 전체 성공·최초 성공으로 집계하지 않습니다. 키/입력 수정이나 승인된 재시도 후 다시 검토합니다.

## 오프라인 증거와 운영 경계

[증거 모음](https://github.com/bridger-kr/bridger-docs/tree/main/docs/gtm)의 이 번들 25개 사례는 합성 행과 기준 시각입니다.
실제 측정값·좌표·주소·provider 응답이 아니며 원본 응답 스키마나 실시간 상태를 검증하지 않습니다.
수원 외 지역, 키 누락, 모호한 위치, 빈 응답, 오래된 값, 기준 시각 누락, 기관 오류를 포함합니다.
권리·키·첨부 문서·실제 smoke와 담당 지원 주체의 확인 전에는 운영 준비 완료로 표시하지 않습니다.
