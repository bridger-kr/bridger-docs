## 사용 예시

<CodeGroup>
  ```bash mcp-gen
  # 카테고리 전체 설치
  mcp-gen install realestate

  # 특정 프리셋만 설치
  mcp-gen install realestate/<preset-name>
  ```

  ```bash 호스팅 Gateway
  curl -X POST https://mcp.datari.kr/mcp \
    -H "x-api-key: $DATARI_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | jq '.result.tools[] | select(.name | startswith("@mcphub/realestate-"))'
  ```
</CodeGroup>

<Note>
  이 페이지는 `apps/docs/scripts/build-presets.mjs`가 `presets/realestate/*.yaml`을
  스캔하여 자동 생성합니다. 직접 수정하지 마세요.
</Note>
