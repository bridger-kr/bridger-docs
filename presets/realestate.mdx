<Tip>
  필요한 도구 이름은 `tools/list` 응답에서 확인한 뒤 `tools/call`로 바로 호출할 수 있습니다.
</Tip>

## 사용 예시

<CodeGroup>
  ```bash 카테고리 서버 조회
  # 이 카테고리의 프리셋 서버와 도구를 확인합니다. (공개 카탈로그 — 인증 불필요)
  curl https://api.bridger.kr/registry/servers \
    | jq '.servers[] | select(.id | startswith("realestate/"))'
  ```

  ```bash 전체 도구 목록 (MCP)
  curl -X POST https://mcp.bridger.kr/mcp \
    -H "x-api-key: $BRIDGER_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | jq '.result.tools[].name'
  ```
</CodeGroup>
