## 지역 통합 도구 (Families)

지역·제공기관별로 나뉜 공공데이터 API를 하나의 도구로 묶은 스펙입니다. `location` 입력만으로 라우팅되어 여러 제공기관을 한 번에 조회합니다.

| 도구 | 설명 | 제공기관 수 | 상태 |
| --- | --- | --- | --- |
| `bus_arrival` | 전국 버스 도착 통합 | 4 | 베타 |
| `bus_location` | 전국 버스 위치 통합 조회 | 2 | 초안 |
| `culture_events` | 전국 문화행사·축제 통합 조회 | 3 | 초안 |
| `emergency_shelter` | 전국 재난 대피시설 통합 | 3 | 초안 |
| `local_heritage` | 지역 문화재 통합 조회 | 2 | 초안 |
| `lodging` | 전국 숙박 통합 조회 | 3 | 초안 |
| `medical_care` | 전국 병원·약국·응급실 통합 조회 | 3 | 초안 |
| `public_library` | 전국 공공도서관 통합 조회 | 2 | 초안 |

## 빠른 사용

```bash
curl -X POST https://mcp.bridger.kr/mcp \
  -H "x-api-key: $BRIDGER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
