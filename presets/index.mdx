## 빠른 사용

```bash
curl -X POST https://mcp.bridger.kr/mcp \
  -H "x-api-key: $BRIDGER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
