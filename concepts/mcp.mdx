**Model Context Protocol (MCP)** 은 Anthropic이 공개한, AI 모델이 외부 도구·데이터·시스템에
표준화된 방식으로 접근하기 위한 오픈 프로토콜입니다. JSON-RPC 2.0 기반이며 STDIO 또는 HTTP +
SSE 트랜스포트를 사용합니다.

## 표준 메서드

| 메서드 | 용도 |
| --- | --- |
| `initialize` | 핸드셰이크 — 프로토콜 버전, capabilities 교환 |
| `tools/list` | Server가 노출하는 도구 메타데이터 조회 |
| `tools/call` | 도구 실행 — `name` + `arguments`를 받아 결과 반환 |
| `resources/list`, `resources/read` | 정적/동적 리소스 조회 |
| `prompts/list`, `prompts/get` | 사전 정의 프롬프트 템플릿 |

## DATA BRIDGE와 MCP

DATA BRIDGE는 **MCP Server 호스팅 플랫폼**입니다. 자체 MCP 서버를 작성·배포·운영하지 않아도,
OpenAPI 스펙만 있으면 즉시 MCP 도구로 변환됩니다.

```text
OpenAPI 스펙 (preset YAML 또는 BYOAPI 등록)
        │
        ▼
  ┌─────────────────────────────┐
  │  DATA BRIDGE Gateway              │
  │  (mcp.datari.kr/mcp)        │
  ├─────────────────────────────┤
  │  • tools/list                │
  │  • tools/call                │
  │  • SSE event stream          │
  └─────────────────────────────┘
        │
        ▼
   Claude / Cursor / 커스텀 에이전트
```

- 한 도메인(`mcp.datari.kr`)에 **수백 개 도구**가 ID로 다중화됩니다 (`@mcphub/weather-forecast`,
  `@user123/my-api`...).
- Server를 별도로 띄울 필요 없이 **API Key 한 개**로 모든 등록 도구 사용.
- 클라이언트는 어떤 MCP 호환 클라이언트(Claude Desktop, Cursor, ChatGPT Actions 어댑터, 자체 SDK)든 그대로 동작.
