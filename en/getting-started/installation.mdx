---
title: "Developer setup"
description: "Configure the API key and base endpoint needed to call the Bridger Gateway directly."
---

Bridger works as a hosted Gateway with no package installation required.
On the client side, you only need to configure an API key and the Gateway URL.

## API key

Create an account at [portal.bridger.kr](https://portal.bridger.kr) and issue a key on the **Auth keys** page.

```bash
export BRIDGER_API_KEY="dk_live_..."
```

## Gateway URL

```bash
export BRIDGER_GATEWAY_URL="https://mcp.bridger.kr/mcp"
```

## Verify the connection

```bash
curl -X POST "$BRIDGER_GATEWAY_URL" \
  -H "x-api-key: $BRIDGER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
