Bridger is a connector that lets AI apps like Claude and ChatGPT answer questions with
Korean public data. There is nothing to install and no API key to issue up front.

## Three steps

<Steps>
  <Step title="Sign in to Bridger">
    Open [portal.bridger.kr](https://portal.bridger.kr) and sign in with **Google** or
    **GitHub**. No separate registration — your social account starts you right away.
  </Step>
  <Step title="Connect Bridger to your AI app">
    Add Bridger as a connector in your AI app's settings. The server URL is the same for
    both apps: `https://mcp.bridger.kr/mcp`.

    - **Claude (web · desktop):** Settings → Connectors →
      **Add custom connector** → name `Bridger`, paste the server URL →
      **Connect**. Follow the step-by-step screens in the [Claude guide](/en/guides/claude).
    - **ChatGPT:** Settings → Apps → enable **Developer mode** →
      Create → name `Bridger`, paste the MCP server URL → **Scan tools**.
      Developer mode may be hidden depending on your plan. See the
      [ChatGPT guide](/en/guides/chatgpt) for details.

    Clicking **Connect** opens the Bridger sign-in and consent (OAuth) screen in your
    browser. Sign in with the same Google · GitHub account from step 1 and click
    **Allow** — done.
  </Step>
  <Step title="Ask your first question">
    Turn the Bridger connector on in a new chat and just ask. The questions below use
    public data from the Bridger catalog.

    {/* example-api: environment/air-quality-realtime */}
    - "Tell me the air quality in Jung-gu, Seoul" — real-time air pollution
    {/* example-api: weather/village-forecast */}
    - "What's the weather in Seoul today?" — KMA short-term forecast
    {/* example-api: realestate/apt-trade */}
    - "Show apartment sale prices in Banpo-dong" — MOLIT apartment transactions
    {/* example-api: economy/stock-price */}
    - "What's Samsung Electronics' stock price?" — FSC stock price information
  </Step>
</Steps>

## If you get stuck

<AccordionGroup>
  <Accordion title="The sign-in / consent window doesn't open">
    Disable your browser's popup blocker and click **Connect** again.
  </Accordion>
  <Accordion title="A question returns nothing or asks for a key">
    Some public-data APIs need a **service key** from the provider (data.go.kr).
    Open the API in the portal's **Government APIs** menu to see whether it works with
    the default key or requires your own service key. See the [API key guide](/en/guides/api-keys).
  </Accordion>
  <Accordion title="Developer mode is missing in ChatGPT">
    It depends on your plan and workspace permissions. Ask your admin for app access,
    or start with the [Claude guide](/en/guides/claude), which needs no developer mode.
  </Accordion>
</AccordionGroup>
