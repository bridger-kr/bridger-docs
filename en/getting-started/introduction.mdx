---
title: "What is Bridger?"
description: "A bridge that lets AI use public-data APIs and BYOAPI directly through the MCP standard."
---

Bridger is a public-data operations gateway inspired by the idea of a bridge between data and tools.
It currently provides {{catalogTotal}} public-data APIs as MCP tools.
({{catalogTotal}} is the number of public-data APIs registered in the public catalog, not the number of MCP tools exposed by presets.)
It handles authentication, parsing, and error handling for public-data APIs on your behalf, and converts them into tools that AI can use directly through the [Model Context Protocol (MCP)](/en/concepts/mcp) standard. A REST API with an OpenAPI spec becomes an AI tool once registered.
