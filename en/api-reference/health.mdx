---
title: "GET /health"
description: "Bridger Gateway liveness health-check endpoint."
---

The lightest endpoint for checking whether the service has started up correctly.
It requires no authentication and can be used directly for load balancer health checks.

## Request

```http
GET /health
```

- Authentication: none
- Content-Type: not applicable

## Response 200

```json
{
  "status": "ok"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `status` | `"ok"` | Started up normally |

## Related endpoints

| Endpoint | Auth | Description |
| --- | --- | --- |
| `GET /health` | none | Liveness — returns `status: ok` |
| `GET /health/ready` | none | Readiness — checks control plane and metadata snapshot. `200 ok` when healthy |

`/health/ready` response example:

```json
{
  "status": "ok",
  "control-plane": "ok",
  "metadata-snapshot": "fresh"
}
```

## cURL

```bash
curl https://mcp.bridger.kr/health
```
