---
title: "GET /registry/tools (Deprecated)"
description: "Deprecated compatibility endpoint; always returns an empty collection."
---

<Warning>
  This legacy endpoint intentionally returns an empty, non-tenant-scoped collection. It does not expose loaded presets or tenant tools. The empty response is expected, not a sign that no presets are available.
</Warning>

To discover tools, send `tools/list` to `POST https://mcp.bridger.kr/mcp?activation=all` with your Bridger API key. Without `activation=all`, the default tool profile is returned.

[Tool discovery and request examples](/en/api-reference/mcp-jsonrpc#toolslist)

## Request

```http
GET https://api.bridger.kr/registry/tools
```

Authentication: not required. This route is on `api.bridger.kr`; `mcp.bridger.kr/registry/tools` returns 404.

## Response 200

```json
{"tools": [], "total": 0}
```
