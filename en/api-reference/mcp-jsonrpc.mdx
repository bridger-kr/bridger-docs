The core MCP call endpoint of the Bridger Gateway. It follows the JSON-RPC 2.0 spec exactly.

## Request headers

```http
POST /mcp HTTP/1.1
Content-Type: application/json
x-api-key: dk_live_...
```

## Common error codes

| Code | Meaning |
| --- | --- |
| `-32600` | Invalid JSON-RPC request |
| `-32601` | Method not found |
| `-32602` | Invalid params (e.g. missing tool name) |
| `-32000` | Internal gateway error |

## tools/list

Returns tool metadata. A plain call returns the **default profile** — a shortlist
of at most 40 tools made of `search_tools`, the most-used tools, and tools
you enabled in the Dashboard. For the full catalog (all tools, including the {{catalogTotal}} public-data APIs), append
`?activation=all` to the endpoint URL.

```text Full catalog (for developers)
POST https://mcp.bridger.kr/mcp?activation=all
```

<Note>
  The default profile keeps tool selection fast and accurate for MCP clients.
  Tools not in the list are still callable via `tools/call`, and
  `search_tools` finds them with natural-language search. Per-connector
  caps also apply — Gemini Enterprise (`?connector=gemini` or `/mcp/gemini`)
  exposes at most 100 actions.
</Note>

### Tool list change notification (`notifications/tools/list_changed`)

When you enable or disable tools in the Dashboard, a
`notifications/tools/list_changed` JSON-RPC notification is pushed over the SSE
stream (`GET /mcp`). Call `tools/list` again on receipt to refresh
your tool list.

### Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/list"
}
```

## tools/call

Runs a single tool. The example calls the KMA ultra-short-term forecast
(`kma_get_ultra_shortcast`).

### Request

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "kma_get_ultra_shortcast",
    "arguments": {
      "base_date": "20210628",
      "base_time": "0630",
      "nx": 55,
      "ny": 127,
      "numOfRows": 10
    }
  }
}
```

### Response 200

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "tool": "kma_get_ultra_shortcast",
    "upstream": {
      "method": "GET",

      "status": 200
    },
    "data": {
      "ok": true,
      "resultCode": "00",
      "resultMessage": "Success",
      "resultCategory": "success",
      "resultAction": "Use the returned data as-is.",
      "retryable": false,
      "items": [
        {
          "baseDate": "20210628",

          "category": "T1H",
          "fcstDate": "20210628",

          "fcstTime": "0700",
          "fcstValue": "1",
          "nx": 55,
          "ny": 127
        }
      ],
      "totalCount": 10,
      "pageNo": 1,
      "numOfRows": 10
    },
    "cacheStatus": "CACHE_STATUS_MISS",
    "auditId": "aud_...",
    "latencyMs": 128,
    "content": [
      {
        "type": "text",
        "text": "{\"ok\":true,\"resultCode\":\"00\",\"resultMessage\":\"Success\",\"resultCategory\":\"success\",\"items\":[…serialized full structuredContent]…}"
      }
    ],
    "structuredContent": {
      "ok": true,
      "resultCode": "00",
      "resultCategory": "success",
      "items": [ { "category": "T1H", "fcstValue": "24.0", "…": "same normalized payload as data" } ],
      "totalCount": 10,
      "numOfRows": 10
    },
    "isError": false
  }
}
```

A failed tool run returns an `isError: true` result instead of a JSON-RPC
error; `structuredContent.error` carries the kind (`kind`), cause, and
bilingual guidance message.

| Field | Description |
| --- | --- |
| `result.tool` | Called tool name |
| `result.upstream.method` | Upstream HTTP method |
| `result.upstream.url` | Final upstream URL (after middleware injection such as ServiceKey; sensitive query params read `REDACTED`) |
| `result.upstream.status` | Upstream HTTP status code |
| `result.data` | Upstream response body (after XML→JSON normalization) |
| `result.data.raw` | Public-data presets preserve the provider's original response in `data.raw` |
| `result.cacheStatus` | Whether the cache was hit (`CACHE_STATUS_HIT`/`CACHE_STATUS_MISS`/`CACHE_STATUS_BYPASS`) |
| `result.auditId` | Audit-log identifier for this call |
| `result.latencyMs` | Tool execution latency (ms) |
| `result.content` | MCP-standard text block — a single item with `structuredContent` serialized as a JSON string (80KB cap, truncated beyond it) |
| `result.structuredContent` | Same normalized payload as `data` (80KB cap, truncated beyond it) |
| `result.isError` | `false` = success, `true` = tool execution error |

## Automatic public-data middleware behavior

When calling a tool from a preset with `isPublicData=true`, the following are applied automatically.

1. ServiceKey injection (`PUBLIC_DATA_SERVICE_KEY`)
2. `lat/lon` → `nx/ny` grid coordinate conversion (KMA DFS)
3. XML/JSON payload normalization
4. Public-data error code → human-readable message mapping

| Code | Message |
| --- | --- |
| `00` | OK |
| `30` | Unregistered service key |
| `31` | Expired service key |
| `32` | Unregistered IP |
| other | `Unknown public-data error (<code>)` |
