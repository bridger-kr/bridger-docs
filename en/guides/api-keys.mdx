Bridger uses two kinds of keys with different purposes. You don't always need both —
it depends on the data you want and the client you call from.

| 이름 | 하는 일 |
| --- | --- |
| **data.go.kr service key** | A key issued by the provider (data.go.kr). Required only for that provider's APIs — APIs callable with the default key don't need one. |

## Issue a Bridger API key

<Steps>
  <Step title="Sign in to the portal">
    Sign in at [portal.bridger.kr](https://portal.bridger.kr) with {{loginProviders}}.
  </Step>

  <Step title="Create an API key">
    Issue a new key on the **Bridger API keys** page in the left menu. It works immediately.
  </Step>

  <Step title="Store the key securely">
    The issued key is shown only once. Store it in an environment variable or a secret manager (e.g. Vault).

    ```bash
    export BRIDGER_API_KEY="dk_live_..."
    ```
  </Step>
</Steps>

## Register a data.go.kr service key

Some of the public-data APIs Bridger calls require a
[Public Data Portal (data.go.kr)](https://www.data.go.kr) service key. To check whether an
API needs one, open its detail page in the portal's **Government APIs** menu — some APIs
work with the default key, others require your own service key. A single service key can
often be reused across multiple APIs from the same provider.

<Steps>
  <Step title="Sign up at data.go.kr">
    Register on the [sign-up page](https://www.data.go.kr/uim/psi/mem/joinIdPwSlct/view.do).
    Skip this step if you already have an account.
  </Step>

  <Step title='Click "Apply" on the API you want'>
    Press the **Apply** button for the API you want on data.go.kr.

    <Tip>You can keep the purpose of use brief. (e.g. "Data lookup for an AI service")</Tip>
  </Step>

  <Step title="Copy the service key after approval">
    Most APIs are **approved instantly**. After approval, copy the
    **general key (Decoding)** from
    [My Page → Usage management](https://www.data.go.kr/iim/api/selectAPIAcInfo.do).

    <Warning>
      Always use the **Decoding** key. The Encoding key (URL-encoded form) is not used by Bridger.
    </Warning>
  </Step>

  <Step title="Register the key in Bridger">
    Paste the key into **Register service key** on the API's detail page under the portal's
    **Government APIs** menu, or add it in the **Public-data service keys** section of
    **Account settings**. It takes effect right away.
  </Step>
</Steps>

## Frequently asked questions

<AccordionGroup>
  <Accordion title="My access application isn't approved">
    Most are auto-approved instantly, but some APIs require provider review. They're usually approved within 1–3 days.
  </Accordion>
  <Accordion title="I have multiple keys — which one do I use?">
    Use the **general key (Decoding)**. The Encoding key is URL-encoded, and Bridger only uses the Decoding key.
  </Accordion>
  <Accordion title="Can I use an API that isn't listed here?">
    A REST API with an OpenAPI spec can be registered directly via [BYOAPI](/en/concepts/byoapi).
    If you'd like your API added as a public preset, contact us at [hello@bridger.kr](mailto:hello@bridger.kr) or via Channel Talk.
  </Accordion>
</AccordionGroup>
