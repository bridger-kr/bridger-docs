title: "Connect to Claude"
description: "How to use Korean public data directly in Claude by adding Bridger MCP as a custom connector — about 2 minutes."
---

Once Claude connects to the Bridger gateway (`https://mcp.bridger.kr/mcp`, Streamable HTTP),
you can use 230+ Korean public-data tools in natural language with no extra installation.
Connection uses your Bridger account over OAuth — no config files to edit.

<Steps>
  <Step title="Add the connector">
    In [claude.ai](https://claude.ai), go to **Customize → Connectors**, click
    **Add custom connector**, and enter this remote MCP server URL:

    ```text
    https://mcp.bridger.kr/mcp
    ```

    On Team/Enterprise plans, an Owner must first register the connector under
    **Organization settings → Connectors → Add → Custom → Web**.

    <Tip>
      Once Bridger is published in the Claude connector directory, you can also find it
      by searching "Bridger" in the **Connectors → +** catalog.
    </Tip>
  </Step>

  <Step title="Sign in with your Bridger account">
    Click **Connect** on the Bridger connector to open the Bridger sign-in (OAuth) page.
    If you don't have an account yet, create one at
    [portal.bridger.kr](https://portal.bridger.kr). After signing in, you can enable
    Bridger from the connectors menu in any chat.
  </Step>

  <Step title="Start using it">
    You can now ask about Korean public data in natural language.

    ```
    What's the weather in Gangnam-gu, Seoul today?
    Show me apartment transaction prices in Banpo-dong.
    ```
  </Step>
</Steps>

## Using Claude Code

```bash
claude mcp add --transport http bridger https://mcp.bridger.kr/mcp
```

On first use, a browser opens for the Bridger OAuth sign-in.

## Connecting with an API key (advanced)

You can also issue a `dk_live_` key from the
[portal.bridger.kr](https://portal.bridger.kr) dashboard and pass it as a request header —
set `Authorization: Bearer <key>` under **Request headers** on the custom connector, or
use the config file below. OAuth is recommended for most users.

```json claude_desktop_config.json
{
  "mcpServers": {
    "bridger": {
      "url": "https://mcp.bridger.kr/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="I don't see any tools">
    Check the Bridger connector status under **Customize → Connectors** and retry
    **Connect** (OAuth sign-in). Also confirm Bridger is enabled in the connectors
    menu of your chat.
  </Accordion>
  <Accordion title="I get an authentication error">
    Make sure the sign-in popup isn't blocked, and check your account at
    [portal.bridger.kr](https://portal.bridger.kr). If you use an API key, try
    re-issuing it.
  </Accordion>
  <Accordion title="Still not working?">
    Contact us at [hello@bridger.kr](mailto:hello@bridger.kr).
  </Accordion>
</AccordionGroup>
