---
title: "Connect to Claude"
description: "How to use Korean public data in claude.ai, Desktop, and mobile via the Bridger custom connector — about 2 minutes."
---

Add Bridger to Claude as a **custom connector** and you can use Korean public-data tools in
natural language with nothing to install. Add it once on the web ([claude.ai](https://claude.ai))
and it's available on the same account's Desktop and mobile apps.

<Note>
  No need to edit a config file (`claude_desktop_config.json`) by hand — **Settings → Connectors**
  is the official way to add a remote MCP server. For the Claude Code CLI, see the
  [dedicated guide](/en/guides/claude-code).
</Note>

<Steps>
  <Step title="Prepare a Bridger account">
    Create an account in the [Dashboard](https://portal.bridger.kr).
    Google and GitHub sign-in are supported.
  </Step>

  <Step title="Open the Connectors screen">
    In [claude.ai](https://claude.ai), go to **Settings → Connectors**
    (same menu path in the Desktop app).
  </Step>

  <Step title="Add the custom connector">
    Choose **Add custom connector** and enter:

    | Field | Value |
    | --- | --- |
    | Name | `Bridger` |
    | Remote MCP server URL | `https://mcp.bridger.kr/mcp` |
  </Step>

  <Step title="Sign in and consent">
    Adding the connector starts Bridger sign-in and OAuth consent in your browser.
    Sign in with Google or GitHub and click **Allow** to finish.
  </Step>

  <Step title="Start using it">
    With the connector linked, ask about Korean public data in natural language.

    ```
    What's the weather in Gangnam-gu, Seoul today?
    Show me apartment transaction prices in Banpo-dong.
    Tell me the fine-dust level in Jung-gu, Seoul.
    ```
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="I don't see Connectors or Add custom connector">
    Custom connectors are gated by plan and region. If the menu isn't visible, check your
    plan — or use [Claude Code](/en/guides/claude-code) or the
    [direct API integration](/en/guides/api) instead.
  </Accordion>
  <Accordion title="The sign-in or consent screen doesn't appear">
    Allow popups and redirects in your browser, and verify the URL is exactly
    `https://mcp.bridger.kr/mcp`.
  </Accordion>
  <Accordion title="Some tools won't run">
    Some public-data APIs need your own service key. Add it under **My service key** in the
    [Dashboard](https://portal.bridger.kr) to enable them.
  </Accordion>
  <Accordion title="I want to disconnect or re-authenticate">
    Open the Bridger connector under **Settings → Connectors**, disconnect it, then add it
    again to re-authenticate.
  </Accordion>
  <Accordion title="Still not working?">
    Contact us at [hello@bridger.kr](mailto:hello@bridger.kr) or via Channel Talk.
  </Accordion>
</AccordionGroup>
