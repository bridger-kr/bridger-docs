---
title: "Connect to ChatGPT"
description: "How to add Bridger as a remote MCP connector in ChatGPT Developer Mode — about 2 minutes."
---

Bridger connects to ChatGPT as a **remote MCP server**. Add
`https://mcp.bridger.kr/mcp` as a connector in Developer Mode to use Korean
public-data tools in natural language. Authentication is handled via OAuth.

<Note>
  Developer Mode is the only supported path for now. Submission to the ChatGPT app
  directory is in progress — once listed, you'll be able to install Bridger directly
  from the directory.
</Note>

<Steps>
  <Step title="Prepare a Bridger account">
    Create an account at [portal.bridger.kr](https://portal.bridger.kr).
    Google and GitHub sign-in are supported.
  </Step>

  <Step title="Enable Developer Mode">
    In ChatGPT **Settings → Apps**, turn on **Developer Mode**. Availability depends on
    your plan and workspace settings.
  </Step>

  <Step title="Create the connector">
    In Developer Mode choose **Create** and enter the MCP server URL.

    ```text MCP Server URL
    https://mcp.bridger.kr/mcp
    ```

    The transport is **Streamable HTTP**.
  </Step>

  <Step title="OAuth consent">
    ChatGPT starts OAuth when the connector is added. Sign in to Bridger
    (Google · GitHub) and click **Allow** to finish.
  </Step>

  <Step title="Start using it">
    Once connected, ask ChatGPT about Korean public data in natural language.

    ```
    Tell me the fine-dust level in Jung-gu, Seoul.
    Check the registration status of business number 220-81-62517.
    What's today's USD exchange rate?
    ```
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="I don't see Developer Mode">
    Developer Mode is gated by plan and workspace (Enterprise/Team, etc.). If it's not
    available, use [Claude](/en/guides/claude), [Gemini CLI](/en/guides/gemini), or the
    [direct API integration](/en/guides/api) instead.
  </Accordion>
  <Accordion title="The OAuth consent screen doesn't appear">
    Verify the URL is exactly `https://mcp.bridger.kr/mcp` and allow browser
    popups/redirects.
  </Accordion>
  <Accordion title="Some tools won't run">
    Certain public-data APIs require a provider key. Register the relevant agency key
    under **Provider Keys** at [portal.bridger.kr](https://portal.bridger.kr).
  </Accordion>
  <Accordion title="Still not working?">
    Contact us at [hello@bridger.kr](mailto:hello@bridger.kr) or via Channel Talk.
  </Accordion>
</AccordionGroup>
