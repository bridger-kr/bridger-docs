---
title: "Connect to ChatGPT"
description: "How to connect Bridger MCP as a custom app (connector) in ChatGPT — about 3 minutes."
---

Once ChatGPT is attached to the Bridger gateway (`https://mcp.bridger.kr/mcp`,
Streamable HTTP), you can use Korean public-data tools in natural language.
Authentication is a Bridger account OAuth login.

<Note>
  Creating a custom MCP app requires **Developer Mode**, and the requirements
  depend on your plan.

  - **Business**: only workspace admins/owners can create apps. Enable developer mode and
    create the app from **Workspace settings → Apps → Create** (each admin turns it on
    for themselves).
  - **Enterprise/Edu**: an admin grants developer access under **Permissions & Roles →
    Connected Data** (RBAC); the member then toggles **Settings → Apps → Advanced
    Settings → Developer mode**.
  - **Plus/Pro**: self-enable at **Settings → Apps → Advanced settings → Developer mode**
    to connect read-only connectors.
  - Free/Go plans are not supported.

  A ChatGPT app-directory listing is in progress; once approved you can install Bridger straight from the directory.
</Note>

<Steps>
  <Step title="Enable developer mode">
    Turn on developer mode per your plan above. If you don't see the toggle, check
    your plan or workspace permissions first.
  </Step>

  <Step title="Create the app (connector)">
    Go to **Settings → Apps → Create** (admins: Workspace settings → Apps → Create),
    enter the following as the MCP server URL, and choose **OAuth** as the auth method.

    ```text Remote MCP Server URL
    https://mcp.bridger.kr/mcp
    ```

    The transport is **Streamable HTTP**. Regular connectors must use exactly
    `/mcp`. `/mcp/openai` is a slim profile reserved for the ChatGPT
    app-directory review — don't use it for manual setup.
  </Step>

  <Step title="Scan tools + OAuth login">
    Click **Scan Tools**. ChatGPT probes the server, then opens the Bridger
    OAuth login. Client registration happens automatically (DCR) — no client ID
    to paste. Log in with your Bridger account and click **Allow** to finish the scan.

    <Tip>
      Don't have an account yet? Sign up first in the
      [Dashboard](https://portal.bridger.kr). Google/GitHub social login is supported.
    </Tip>
  </Step>

  <Step title="Create and start using it">
    When the scan finishes, click **Create**. The app shows up under Settings →
    Apps → Enabled Apps with a **Dev** label. Select it in a new chat and ask for
    Korean data in natural language.

    ```
    What's the weather in Gangnam-gu, Seoul tomorrow?
    Tell me the current fine-dust level in Seoul.
    Show me apartment trade prices in Banpo-dong.
    ```

    <Note>
      Tools that need a data.go.kr key (e.g. apartment trades) return a
      **service-key registration notice** instead of data when your account has none.
      Add **My service key** in the [Dashboard](https://portal.bridger.kr) to get live results.
    </Note>
  </Step>
</Steps>

## Enabling more tools

Right after connecting, the tool list is limited to the default profile —
`search_tools`, the most-used tools, and tools you enabled — to keep the
client fast. Tools not in the list are still reachable: `search_tools`
finds them with natural-language search and they can be called right away.

- **Enable tools in the Dashboard**: activate the public-data APIs you need in the
  [Dashboard](https://portal.bridger.kr); they are always included in the default
  profile from the next `tools/list`.
- **Full catalog (for developers)**: append `?activation=all` to the connector
  URL to receive the full catalog (all {{catalogTotal}} public-data tools included), e.g. `https://mcp.bridger.kr/mcp?activation=all`

## Troubleshooting

<AccordionGroup>
  <Accordion title="No developer-mode toggle / Create button">
    Check that your plan supports developer mode. On Business only admins/owners can
    create apps; on Enterprise/Edu an admin must grant access via RBAC.
  </Accordion>
  <Accordion title="Scan Tools fails">
    Verify `https://mcp.bridger.kr/mcp` exactly. `/mcp/openai` is the
    app-directory review profile — regular connector setup uses `/mcp`.
    Also check that browser popups/redirects aren't blocked.
  </Accordion>
  <Accordion title="It keeps asking me to log in again">
    This can be an OAuth token-refresh issue. Retry shortly; if it persists, delete
    the connector and create it again.
  </Accordion>
  <Accordion title="No data returned">
    Some public-data APIs undergo maintenance at night. Please try again later.
  </Accordion>
  <Accordion title="Still not working?">
    Contact [hello@bridger.kr](mailto:hello@bridger.kr).
  </Accordion>
</AccordionGroup>
