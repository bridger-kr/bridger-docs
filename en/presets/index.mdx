## Region-unified tools (families)

Specs that merge region- or provider-split public APIs into a single tool. Pass a `location` input and the family routes to the right providers for you.

## Quick start

```bash
curl -X POST https://mcp.bridger.kr/mcp \
  -H "x-api-key: $BRIDGER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
