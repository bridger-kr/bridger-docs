<Warning>A business status is not a transaction approval or a trust score. Credit, fraud, beneficial-owner or identity verification and street-address verification are not provided; the final call stays with the responsible operator.</Warning>

## 1. Start with a question like this

When a responsible operator screens a new counterparty, questions look like this:

- "Check whether business registration number 123-45-67890 is active."
- "Confirm the open/closed status of these three numbers: 123-45-67890, 987-65-43210, 555-22-10101."
- "Check the status of a batch of registration numbers at once."

Ask in a new conversation in an app connected to [Bridger](/en/guides/claude); the app picks the matching registered tool and calls it.

## 2. Which tools run

The tools below serve the examples above. Presets and tools are listed in the
[civil catalog](/en/presets/civil).

| Preset | Tool | Purpose |
| --- | --- | --- |
| `civil/business-registration` | `getBusinessRegistrationStatus` | Query NTS status and tax type by registration number. Numbers are passed as a list (`businessRegistrationNumbers`), up to 100 per call |
| `civil/business-registration` | `validateBusinessRegistration` | Registration-information matching against representative name and opening date. The existing business-information widget uses this tool |
| `resolve_location` | Region normalization | Converts a Korean region name or coordinates into administrative codes / weather grid. See [Korean data](/en/concepts/korean-data) |

`resolve_location` is not a street-address validator. Building- and postal-address
validation is unsupported, and ambiguous place names resolve once you say which one you mean.

In a developer environment you can call the tools directly with `tools/list` ·
`tools/call` as shown in the [first tool guide](/en/getting-started/first-tool). Provider quota
limits apply (status lookup: 100 per call, 1M per day, per the catalog table).

## 3. How to read the answer

| Item | How to read it |
| --- | --- |
| `businessStatusName` / `businessStatusCode` | Open/closed status as registered with the NTS. A "closed" state is still a successful lookup, not an error |
| `taxTypeName` / `taxTypeCode` | Tax type (general, simplified, etc.) |
| `closedOn` | Closure date — shown only for closed entities |
| Registration-matching result | Separate from status lookup. Status lookup reads the registered state; matching compares representative name and opening date |

A status lookup is exactly that: the current registered state. Do not stretch it
into an approval decision or a credit judgment; the operator makes the final call
after further review.

## Boundaries of this task

- Only enter registration numbers you lawfully hold. Do not paste numbers or queries into public examples or documents.
- If the answer comes back empty or with an error, re-check the number first; if the input is right and the failure repeats, distinguish key/API setup problems from lookup problems when asking for support.
- The provider is the NTS ([Public Data Portal 15081808](https://www.data.go.kr/data/15081808/openapi.do)). Provider refresh cycles apply, so re-query before a decision if the data is stale.
