Claude나 ChatGPT 없이도 DATA BRIDGE Gateway는 REST와 표준 MCP SDK로 직접 호출할 수 있습니다.

<Steps>
  <Step title="API 키 발급">
    [어드민 대시보드](https://admin.datari.kr/settings)에서 API 키를 발급받습니다.
    [API 키 가이드](/guides/api-keys)도 함께 참고하세요.
  </Step>

  <Step title="REST API 호출">
    표준 REST 엔드포인트로 호출합니다.

    <CodeGroup>
      ```bash 도구 목록
      curl -X GET https://mcp.datari.kr/api/v1/tools \
        -H "Authorization: Bearer YOUR_API_KEY" \
        -H "Content-Type: application/json"
      ```

      ```bash 도구 실행
      curl -X POST https://mcp.datari.kr/api/v1/tools/weather/forecast \
        -H "Authorization: Bearer YOUR_API_KEY" \
        -H "Content-Type: application/json" \
        -d '{
          "city": "서울",
          "district": "강남구"
        }'
      ```
    </CodeGroup>
  </Step>

  <Step title="MCP SDK 연동 (Node.js)">
    프로그래밍 방식으로 연동하려면 공식 MCP SDK를 사용하세요.

    ```bash 설치
    npm install @modelcontextprotocol/sdk
    ```

    ```javascript client.js
    import { Client } from "@modelcontextprotocol/sdk/client/index.js";
    import { SSEClientTransport } from "@modelcontextprotocol/sdk/client/sse.js";

    const transport = new SSEClientTransport(
      new URL("https://mcp.datari.kr/sse"),
      {
        requestInit: {
          headers: {
            Authorization: "Bearer YOUR_API_KEY",
          },
        },
      }
    );

    const client = new Client({
      name: "my-app",
      version: "1.0.0",
    });

    await client.connect(transport);

    // 도구 목록 조회
    const tools = await client.listTools();
    console.log(tools);

    // 도구 실행
    const result = await client.callTool({
      name: "weather_forecast",
      arguments: {
        city: "서울",
        district: "강남구",
      },
    });
    console.log(result);
    ```
  </Step>

  <Step title="MCP SDK 연동 (Python)">
    동일한 흐름을 Python으로도 구현할 수 있습니다.

    ```bash 설치
    pip install mcp
    ```

    ```python client.py
    from mcp import ClientSession
    from mcp.client.sse import sse_client
    import asyncio

    async def main():
        headers = {"Authorization": "Bearer YOUR_API_KEY"}

        async with sse_client(
            "https://mcp.datari.kr/sse",
            headers=headers,
        ) as (read, write):
            async with ClientSession(read, write) as session:
                await session.initialize()

                tools = await session.list_tools()
                print(tools)

                result = await session.call_tool(
                    "weather_forecast",
                    arguments={"city": "서울", "district": "강남구"},
                )
                print(result)

    asyncio.run(main())
    ```
  </Step>

  <Step title="BYOAPI — 자체 API 등록">
    OpenAPI 스펙이 있는 어떤 API든 DATA BRIDGE 도구로 등록할 수 있습니다.
    자세한 흐름은 [BYOAPI 개념 문서](/concepts/byoapi)를 참고하세요.

    ```bash API 등록
    curl -X POST https://mcp.datari.kr/api/v1/register \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "spec_url": "https://api.example.com/openapi.json",
        "name": "my-service",
        "auth": {
          "type": "bearer",
          "token": "SERVICE_API_KEY"
        }
      }'
    ```
  </Step>
</Steps>

## API 레퍼런스 요약

| 메서드 | 경로 | 설명 |
| ------ | ----- | ---- |
| `GET`  | `/api/v1/tools`         | 전체 도구 목록 |
| `POST` | `/api/v1/tools/:id`     | 도구 실행 |
| `GET`  | `/api/v1/servers`       | 서버 목록 |
| `POST` | `/api/v1/register`      | BYOAPI 등록 |
| `GET`  | `/sse`                  | MCP SSE 엔드포인트 |
| `POST` | `/mcp`                  | JSON-RPC (`tools/list`, `tools/call`) |

전체 스펙은 [API Reference](/api-reference/introduction) 탭을 참고하세요.
