Bridger에는 용도가 다른 두 종류의 키가 있습니다. 둘 다 항상 필요한 것은 아니며,
사용하려는 데이터와 클라이언트에 따라 달라집니다.

| 키 | 용도 |
| --- | --- |
| **브릿저 API 키** | 외부 AI 클라이언트나 자체 서버에서 Bridger Gateway를 호출할 때 사용합니다 (`dk_live_…`). 대시보드에서의 시험 호출에는 필요하지 않습니다. |
| **공공데이터포털 서비스키** | 제공기관(data.go.kr)이 발급하는 키입니다. 해당 기관 API를 사용할 때만 필요하며, 무료 체험 키로 호출 가능한 API에는 필요하지 않습니다. |

## 브릿저 API 키 발급

<Steps>
  <Step title="대시보드 로그인">
    [portal.bridger.kr](https://portal.bridger.kr)에서 {{loginProviders}}로 로그인합니다.
  </Step>

  <Step title="API 키 생성">
    왼쪽 메뉴의 **인증키** 페이지에서 새 키를 발급합니다. 발급 즉시 사용할 수 있습니다.
  </Step>

  <Step title="키를 안전하게 저장">
    발급된 키는 한 번만 표시됩니다. 환경변수 또는 시크릿 매니저(예: Vault)에 저장하세요.

    ```bash
    export BRIDGER_API_KEY="dk_live_..."
    ```
  </Step>
</Steps>

## 공공데이터포털 서비스키 등록

Bridger가 호출하는 공공데이터 API 중 일부는 [공공데이터포털(data.go.kr)](https://www.data.go.kr)
서비스키가 필요합니다. 어떤 API에 필요한지는 대시보드의 **공공데이터** 메뉴에서 각 API 상세
화면을 열면 확인할 수 있습니다 — 무료 체험 키로 호출 가능한 API도 있고, 내 서비스키를
등록해야 하는 API도 있습니다. 한 번 발급받은 서비스키는 같은 제공기관의 여러 API에
재사용할 수 있는 경우가 많습니다.

<Steps>
  <Step title="data.go.kr 회원가입">
    [회원가입 페이지](https://www.data.go.kr/uim/psi/mem/joinIdPwSlct/view.do)에서 가입합니다.
    이미 계정이 있다면 이 단계를 건너뛰세요.
  </Step>

  <Step title='원하는 API "활용신청" 클릭'>
    data.go.kr에서 사용할 API의 **활용신청** 버튼을 누릅니다.

    <Tip>활용 목적은 간단히 입력해도 됩니다. (예: "AI 서비스 데이터 조회")</Tip>
  </Step>

  <Step title="승인 후 인증키 복사">
    대부분의 API는 **즉시 승인**됩니다. 승인 후
    [마이페이지 → 활용 관리](https://www.data.go.kr/iim/api/selectAPIAcInfo.do)에서
    **일반 인증키 (Decoding)** 를 복사하세요.

    <Warning>
      반드시 **Decoding** 키를 사용하세요. Encoding 키(URL 인코딩된 형태)는 Bridger에서 사용하지
      않습니다.
    </Warning>
  </Step>

  <Step title="Bridger에 키 등록">
    대시보드 **공공데이터** 메뉴에서 해당 API 상세 화면의 **인증키 등록하기**로 복사한 키를 입력하거나,
    **계정 설정**의 **공공데이터 서비스키 관리** 섹션에서 등록합니다. 등록 후 바로 사용할 수 있습니다.
  </Step>
</Steps>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="활용신청이 승인되지 않아요">
    대부분 즉시 자동 승인이지만, 일부 API는 기관 검토가 필요합니다. 보통 1–3일 내 승인됩니다.
  </Accordion>
  <Accordion title="인증키가 여러 개인데 어떤 걸 써야 하나요?">
    **일반 인증키 (Decoding)** 를 사용하세요. Encoding 키는 URL 인코딩된 형태로,
    Bridger에서는 Decoding 키만 사용합니다.
  </Accordion>
  <Accordion title="여기 없는 API도 사용할 수 있나요?">
    OpenAPI 스펙이 있는 REST API를 [BYOAPI](/concepts/byoapi)로 직접 등록할 수 있습니다.
    내 API를 공용 프리셋으로 추가하고 싶다면 [hello@bridger.kr](mailto:hello@bridger.kr) 또는 채널톡으로 문의해 주세요.
  </Accordion>
</AccordionGroup>
