## Bridger API Key 발급

<Steps>
  <Step title="어드민 대시보드 접속">
    [admin.datari.kr](https://admin.datari.kr)에서 계정을 만듭니다.
    구글 / 카카오 소셜 로그인을 지원합니다.
  </Step>

  <Step title="API 키 생성">
    **Settings → API Keys → Create new key**를 클릭하면 즉시 발급됩니다.
  </Step>

  <Step title="키를 안전하게 저장">
    발급된 키는 한 번만 표시됩니다. 환경변수 또는 시크릿 매니저(예: Vault)에 저장하세요.

    ```bash
    export DATA_BRIDGE_API_KEY="dk_live_..."
    ```
  </Step>
</Steps>

## data.go.kr 인증키 신청

Bridger가 호출하는 공공데이터 API의 상당수는 [공공데이터포털(data.go.kr)](https://www.data.go.kr)
인증키가 필요합니다. 한 번 발급받은 인증키는 같은 제공기관의 여러 API에 재사용할 수 있는
경우가 많습니다.

<Steps>
  <Step title="data.go.kr 회원가입">
    [회원가입 페이지](https://www.data.go.kr/uim/psi/mem/joinIdPwSlct/view.do)에서 가입합니다.
    이미 계정이 있다면 이 단계를 건너뛰세요.
  </Step>

  <Step title='원하는 API "활용신청" 클릭'>
    [admin.datari.kr](https://admin.datari.kr)의 Provider Keys 화면 또는 data.go.kr에서 사용할 API의
    **활용신청** 버튼을 누릅니다.

    <Tip>활용 목적은 간단히 입력해도 됩니다. (예: "AI 서비스 데이터 조회")</Tip>
  </Step>

  <Step title="승인 후 인증키 복사">
    대부분의 API는 **즉시 승인**됩니다. 승인 후
    [마이페이지 → 활용 관리](https://www.data.go.kr/iim/api/selectAPIAcInfo.do)에서
    **일반 인증키 (Decoding)** 를 복사하세요.

    <Warning>
      반드시 **Decoding** 키를 사용하세요. Encoding 키(URL 인코딩된 형태)는 Bridger에서 사용하지
      않습니다.
    </Warning>
  </Step>

  <Step title="Bridger에 키 입력">
    Bridger 어드민 대시보드의 **Settings → Provider Keys**에 복사한 인증키를 입력하면
    바로 사용할 수 있습니다. 하나의 인증키로 같은 제공기관의 여러 API를 사용할 수 있는 경우가
    많습니다.
  </Step>
</Steps>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="활용신청이 승인되지 않아요">
    대부분 즉시 자동 승인이지만, 일부 API는 기관 검토가 필요합니다. 보통 1–3일 내 승인됩니다.
  </Accordion>
  <Accordion title="인증키가 여러 개인데 어떤 걸 써야 하나요?">
    **일반 인증키 (Decoding)** 를 사용하세요. Encoding 키는 URL 인코딩된 형태로,
    Bridger에서는 Decoding 키만 사용합니다.
  </Accordion>
  <Accordion title="여기 없는 API도 사용할 수 있나요?">
    OpenAPI 스펙이 있는 어떤 API든 [BYOAPI](/concepts/byoapi)로 직접 등록할 수 있습니다. (추후 제공 예정)
    내 API를 공용 프리셋으로 추가하고 싶다면 [support@datari.kr](mailto:support@datari.kr) 또는 채널톡으로 문의해 주세요.
  </Accordion>
</AccordionGroup>
