Gemini Enterprise(Google Workspace)의 **커스텀 MCP 서버** 커넥터로 Bridger를 연결하면,
230+ 한국 공공데이터 도구를 Gemini 에이전트 액션으로 사용할 수 있습니다.

전송 방식은 **Streamable HTTP**, 인증은 **OAuth 2.0 Authorization Code + PKCE(S256)**입니다.
Gemini Enterprise는 동적 클라이언트 등록(DCR)을 지원하지 않으므로, 관리자가 미리 발급한
정적 confidential 클라이언트의 client ID/secret을 콘솔에 직접 입력합니다.

<Note>
  이 설정은 **Bridger 운영자(플랫폼 관리자)와 Google Workspace 관리자**가 함께 진행합니다.
  일반 사용자 설정 가이드는 [ChatGPT 연결](/guides/chatgpt)을 참고하세요.
</Note>

## 1. 정적 OAuth 클라이언트 발급 (Bridger 관리자)

관리자 게이트 엔드포인트 `POST /api/v1/admin/oauth-clients`로 만료되지 않는
confidential 클라이언트를 발급합니다. 게이트웨이 관리자 API 키(`GATEWAY_API_KEY`)가 필요합니다.

```bash
curl -X POST https://mcp.datari.kr/api/v1/admin/oauth-clients \
  -H "x-api-key: $GATEWAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "client_name": "Gemini Enterprise",
    "redirect_uris": ["https://vertexaisearch.cloud.google.com/oauth-redirect"],
    "grant_types": ["authorization_code", "refresh_token"],
    "token_endpoint_auth_method": "client_secret_basic",
    "scope": "tools:read tools:execute offline_access"
  }'
```

<Warning>
  `redirect_uris`에는 Google이 고정으로 사용하는
  `https://vertexaisearch.cloud.google.com/oauth-redirect`를 **정확히** 등록해야 합니다.
  등록되지 않은 리다이렉트는 승인 요청에서 거부됩니다.
</Warning>

응답(201)에서 `client_id`와 `client_secret`을 확보합니다.

```json
{
  "client_id": "mcp_1a2b3c...",
  "client_secret": "mcs_9f8e7d...",
  "client_secret_expires_at": 0,
  "redirect_uris": ["https://vertexaisearch.cloud.google.com/oauth-redirect"],
  "scope": "tools:read tools:execute offline_access"
}
```

`client_secret_expires_at: 0`은 만료 없음을 뜻합니다. 이 값은 발급 시 한 번만 보여지므로
안전한 곳(보안 비밀 저장소)에 보관하세요.

<Accordion title="대안: 동적 클라이언트 등록(DCR)으로 발급하기">
  공개 DCR 엔드포인트로도 클라이언트를 만들 수 있습니다.

  ```bash
  curl -X POST https://mcp.datari.kr/oauth/register \
    -H "Content-Type: application/json" \
    -d '{
      "client_name": "Gemini Enterprise",
      "redirect_uris": ["https://vertexaisearch.cloud.google.com/oauth-redirect"],
      "grant_types": ["authorization_code", "refresh_token"],
      "scope": "tools:read tools:execute offline_access"
    }'
  ```

  <Warning>
    DCR 클라이언트는 **30일 후 만료**됩니다(`client_secret_expires_at` 참고).
    Gemini Enterprise는 재등록을 자동으로 수행하지 않으므로, 장기 운영에는 반드시
    관리자 엔드포인트로 발급한 정적 클라이언트를 사용하세요.
  </Warning>
</Accordion>

## 2. Gemini Enterprise 데이터 스토어 설정 (Workspace 관리자)

Google 관리 콘솔에서 Gemini Enterprise **데이터 스토어/커넥터 → 커스텀 MCP 서버** 추가 시
다음 값을 입력합니다.

| Google 필드 | 입력 값 |
| --- | --- |
| MCP Server URL | `https://mcp.datari.kr/mcp/gemini` |
| Authorization URL | `https://mcp.datari.kr/oauth/authorize` |
| Token URL | `https://mcp.datari.kr/oauth/token` |
| Client ID | 1단계에서 발급한 `mcp_...` |
| Client Secret | 1단계에서 발급한 `mcs_...` |
| Scopes (공백 구분) | `tools:read tools:execute offline_access` |
| PKCE | 활성화 — Bridger는 **S256 필수** |
| Redirect URI | `https://vertexaisearch.cloud.google.com/oauth-redirect` (Google 고정, 1단계에 등록된 값) |

<Tip>
  `/mcp/gemini` 전용 엔드포인트는 도구 목록을 최대 **100개**로 잘라 내려줍니다.
  Gemini Enterprise 데이터 스토어당 활성화 가능한 액션 상한이 100개이므로,
  이 경로로 연결하면 상한을 넘지 않습니다. 범용 `/mcp` 경로로도 연결할 수 있지만
  도구 수가 100개를 넘는 환경에서는 `/mcp/gemini`를 권장합니다.
</Tip>

## 3. 동작 확인

1. 데이터 스토어를 저장하면 Gemini가 OAuth 인증을 시작합니다. Bridger 로그인 후
   동의 화면에서 클라이언트명·스코프·리다이렉트를 확인하고 **Allow**를 누릅니다.
2. 커넥터의 **Actions** 목록에서 도구가 임포트되었는지 확인하고, 사용할 액션을
   최대 100개까지 활성화합니다.
3. Gemini에서 한국 공공데이터 질의를 실행해 액션 호출을 확인합니다.

## 스코프 의미

| 스코프 | 의미 |
| --- | --- |
| `tools:read` | 도구 목록 조회(`tools/list`) |
| `tools:execute` | 도구 실행(`tools/call`) |
| `offline_access` | 리프레시 토큰 발급 — 장기 연결 유지 |

<Note>
  `resource` 파라미터(RFC 8707)는 보내지 않아도 됩니다. 생략하면 게이트웨이의
  canonical 리소스(`https://mcp.datari.kr/mcp`)로 자동 바인딩됩니다. 값을 보내는
  클라이언트는 반드시 이 canonical 값과 정확히 일치해야 합니다.
</Note>

## 문제 해결

<AccordionGroup>
  <Accordion title="승인 요청이 invalid_target / invalid_redirect_uri로 실패해요">
    클라이언트에 등록된 리다이렉트가 `https://vertexaisearch.cloud.google.com/oauth-redirect`와
    정확히 일치하는지 확인하세요. `resource`를 보내는 경우 `https://mcp.datari.kr/mcp`와
    일치해야 하며, 생략하면 자동으로 canonical로 바인딩됩니다.
  </Accordion>
  <Accordion title="PKCE 오류가 발생해요">
    Bridger는 PKCE `S256`만 허용합니다. 커넥터 설정에서 PKCE를 활성화하고,
    plain/생략 방식은 지원되지 않습니다.
  </Accordion>
  <Accordion title="client_id가 갑자기 인식되지 않아요">
    DCR로 발급한 클라이언트는 30일 만료입니다. `POST /api/v1/admin/oauth-clients`로
    발급한 정적 클라이언트인지 확인하세요.
  </Accordion>
  <Accordion title="일부 도구가 목록에 없어요">
    `/mcp/gemini` 경로는 100개로 절단됩니다. 노출할 도구를 좁히려면 운영자가
    `MCP_GEMINI_CURATED_TOOLS`로 큐레이션 목록을 지정할 수 있습니다.
  </Accordion>
  <Accordion title="그래도 해결이 안 되면">
    [이메일](mailto:support@datari.kr) 또는 채널톡으로 문의해 주세요.
  </Accordion>
</AccordionGroup>
