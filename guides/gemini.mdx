---
title: "Gemini에 연결하기"

---

Bridger는 **Gemini CLI**(개발자용 터미널 도구)와 **Gemini Enterprise**(조직용)에서
MCP 서버로 연결할 수 있습니다.

<Note>
  **소비자용 Gemini 앱**(gemini.google.com 웹 · 모바일 앱)은 연결 대상이 아닙니다.
  앱의 커스텀 MCP 연결("Custom apps for Spark")은 미국 · 영어 환경의 개인 계정에만
  제공되는 기능이라 한국 계정에서는 메뉴가 나타나지 않습니다. 한국에서는 아래
  Gemini CLI 또는 Gemini Enterprise 경로를 사용하세요.
</Note>

## Gemini CLI

`~/.gemini/settings.json`에 MCP 서버를 등록합니다.

```json ~/.gemini/settings.json
{
  "mcpServers": {
    "bridger": {
      "httpUrl": "https://mcp.bridger.kr/mcp"
    }
  }
}
```

또는 명령 한 줄로 등록할 수도 있습니다.

```bash
gemini mcp add --transport http bridger https://mcp.bridger.kr/mcp
```

첫 사용 시 브라우저가 열리며 Bridger 로그인(Google · GitHub)과 권한 동의가 진행됩니다.
CLI 안에서 `/mcp`를 입력하면 서버 연결 상태와 인증 메뉴를 확인할 수 있습니다.

<Tip>
  **CLI 확장 한 줄 설치는 준비 중입니다.** 공개되면
  `gemini extensions install https://github.com/bridger-kr/bridger-gemini-extension`
  한 줄로 설치할 수 있습니다. 지금은 위 `settings.json` 방식을 사용하세요.
</Tip>

## Gemini Enterprise

조직의 Gemini Enterprise에서는 관리자가 커스텀 MCP 커넥터를 등록합니다.
커넥터 설정 화면에 다음 값을 입력하세요.

| 입력 항목 | 값 |
| --- | --- |
| MCP server URL | `https://mcp.bridger.kr/mcp` |
| Transport | Streamable HTTP |
| Authorization URL | `https://api.bridger.kr/oauth/authorize` |
| Token URL | `https://api.bridger.kr/oauth/token` |
| Client ID / Client secret | Bridger에 발급 요청 ([hello@bridger.kr](mailto:hello@bridger.kr)) |
| Scopes (공백 구분) | `tools:read tools:execute offline_access` |
| PKCE | 활성화 — Bridger는 **S256**만 허용 |
| Redirect URI | `https://vertexaisearch.cloud.google.com/oauth-redirect` (Google 고정 값) |

<Note>
  Gemini Enterprise는 동적 클라이언트 등록(DCR)을 지원하지 않아, 사전 등록된 만료 없는
  confidential client가 필요합니다. 위 리다이렉트 URI로 발급을 요청해 주시면 Bridger에서
  Client ID · secret을 발급해 드립니다. secret은 한 번만 전달되니 안전하게 보관하세요.
</Note>

| 스코프 | 의미 |
| --- | --- |
| `tools:read` | 도구 목록 조회(`tools/list`) |
| `tools:execute` | 도구 실행(`tools/call`) |
| `offline_access` | 리프레시 토큰 발급 — 장기 연결 유지 |

<Tip>
  Gemini Enterprise는 커넥터당 활성화할 수 있는 액션이 최대 100개입니다. Bridger는
  Gemini Enterprise 연결에서 도구 목록을 100개 이내로 맞춰 내려주므로 상한을 넘지 않습니다.
  저장 후 커넥터의 **Actions** 목록에서 사용할 액션을 켜 주세요.
</Tip>

## Gemini API (GenAI SDK) 개발자 샘플

Google GenAI SDK(`google-genai`)의 실험적 MCP 지원으로, MCP `ClientSession`을
`generate_content`의 도구로 직접 넘길 수 있습니다. Gemini가 필요한 도구를 골라
`tools/call`까지 수행합니다.

<Warning>
  SDK의 MCP 지원은 **실험적**이며 도구 호출만 됩니다(리소스·프롬프트 미지원).
  안정성이 필요한 프로덕션 경로는 위 Gemini CLI/Enterprise 연결을 사용하세요.
</Warning>

```bash
pip install "mcp>=2" google-genai
```

```python gemini_mcp_sample.py
import asyncio
import os

from google import genai
from google.genai import types
from mcp import ClientSession
from mcp.client.streamable_http import (
    create_mcp_http_client,
    streamable_http_client,
)

async def main() -> None:
    # Gemini 전용 엔드포인트는 도구 목록을 100개로 맞춥니다. 범용 엔드포인트는
    # https://mcp.bridger.kr/mcp 입니다.
    # 브릿저 API 키(dk_live_…)를 대시보드에서 발급받아 x-api-key로 보냅니다.
    client = create_mcp_http_client(
        headers={"x-api-key": os.environ["BRIDGER_API_KEY"]}
    )
    async with streamable_http_client(
        "https://mcp.bridger.kr/mcp/gemini", http_client=client
    ) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])
            response = client.models.generate_content(
                model="gemini-2.5-flash",
                contents="서울 중구 날씨를 브릿저 도구로 알려줘",
                config=types.GenerateContentConfig(tools=[session]),
            )
            print(response.text)

asyncio.run(main())
```

이 샘플과 [API SDK 가이드](/guides/api)의 Python 예시는 `mcp` Python SDK
**2.x** 기준으로 통일되어 있습니다. 1.x의 `streamablehttp_client`는 2.x에서
제거되었고, 2.x에서는 헤더를 키워드로 받지 않으므로
`create_mcp_http_client(headers=…)`로 만든 클라이언트를 `http_client`로
넘깁니다.

<AccordionGroup>
  <Accordion title="연결 확인 — 실제 실행 결과">
    도구 목록(`tools/list`)과 `search_tools` 검색은 API 키 없이도 익명으로
    열립니다. 아래는 같은 코드로 `https://mcp.bridger.kr/mcp`에 붙은 실제
    출력입니다(2026-10-06).

    ```text
    tools/list: 5 tools
    first: search_tools
    ```

    Gemini 전용 경로 `/mcp/gemini`는 100개까지의 정제된 카탈로그를 반환하고,
    공공데이터 도구 실행(`tools/call`)은 활성화 정책과 서비스키가 필요합니다 —
    익명으로 호출하면 `grant verification failed`로 거절됩니다.
  </Accordion>
  <Accordion title="search_tools 응답 형식 주의">
    Bridger `search_tools`는 결과를 MCP `content` 배열이 아니라 구조화된
    JSON 객체로 돌려줍니다. `mcp` SDK의 `session.call_tool("search_tools", …)`은
    `CallToolResult` 검증(`content` 필드 필수)에서 실패할 수 있으니, SDK 경로에서는
    GenAI `tools=[session]`에 위임하거나 원시 JSON-RPC POST(`tools/call`)로
    읽는 편이 안전합니다.
  </Accordion>
</AccordionGroup>

## 문제 해결

<AccordionGroup>
  <Accordion title="Gemini CLI에서 서버가 안 보여요">
    `~/.gemini/settings.json`의 JSON 형식과 `mcpServers` 키 위치를 확인하고,
    `gemini mcp list`로 등록 여부를 확인하세요.
  </Accordion>
  <Accordion title="인증 브라우저가 열리지 않아요">
    CLI에서 `/mcp` → `bridger` 선택 후 인증을 다시 시도하세요. 헤드리스 환경이라면
    브라우저가 있는 환경에서 설정 파일을 만든 뒤 사용하세요.
  </Accordion>
  <Accordion title="Enterprise 승인이 invalid_redirect_uri / invalid_target으로 실패해요">
    발급받은 클라이언트의 리다이렉트가 `https://vertexaisearch.cloud.google.com/oauth-redirect`와
    정확히 일치하는지 확인하세요. `resource` 값은 생략해도 되며, 보낸다면
    `https://mcp.bridger.kr/mcp`와 정확히 일치해야 합니다.
  </Accordion>
  <Accordion title="Enterprise에서 PKCE 오류가 나요">
    커넥터 설정에서 PKCE를 켜고 방식을 `S256`으로 지정하세요. plain 방식이나 PKCE 생략은
    지원되지 않습니다.
  </Accordion>
  <Accordion title="어떤 도구는 실행이 안 돼요">
    일부 공공데이터 API는 내 인증키(서비스키)가 필요합니다. [대시보드](https://portal.bridger.kr)에서
    해당 기관의 **내 인증키(서비스키)**를 등록하면 사용할 수 있습니다.
  </Accordion>
  <Accordion title="그래도 해결이 안 되면">
    [hello@bridger.kr](mailto:hello@bridger.kr) 또는 채널톡으로 문의해 주세요.
  </Accordion>
</AccordionGroup>
