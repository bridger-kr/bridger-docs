---

Claude에 Bridger를 **커스텀 커넥터**로 추가하면 별도 설치 없이 한국 공공데이터 도구를
자연어로 사용할 수 있습니다. 웹([claude.ai](https://claude.ai))에서 한 번 추가하면
같은 계정의 Desktop · 모바일 앱에서도 그대로 사용됩니다.

<Note>
  설정 파일(`claude_desktop_config.json`)을 직접 편집할 필요가 없습니다. 원격 MCP 서버는
  **Settings → Connectors** 화면에서 추가하는 방식이 공식 경로입니다. CLI 도구인
  Claude Code는 [별도 가이드](/guides/claude-code)를 참고하세요.
</Note>

<Steps>
  <Step title="Bridger 계정 준비">
    [대시보드](https://portal.bridger.kr)에서 계정을 만듭니다.
    Google · GitHub 로그인을 지원합니다.
  </Step>

  <Step title="Connectors 화면 열기">
    [claude.ai](https://claude.ai)에서 **Settings → Connectors** 로 이동합니다.
    (새 화면에서는 **Customize → Connectors**, Desktop 앱도 동일한 메뉴 경로입니다.)
  </Step>

  <Step title="커스텀 커넥터 추가">
    **Add custom connector** 를 선택하고 다음 값을 입력합니다.

    | 항목 | 값 |
    | --- | --- |
    | Name | `Bridger` |
    | Remote MCP server URL | `https://mcp.bridger.kr/mcp` |

    Team/Enterprise 플랜은 Owner가 **Organization settings → Connectors → Add → Custom → Web**으로
    먼저 커넥터를 등록해야 합니다.

    <Tip>
      브릿저가 Claude 커넥터 디렉터리에 게시되면 **Connectors → +** 목록에서 "Bridger"를
      검색해 바로 추가할 수도 있습니다.
    </Tip>
  </Step>

  <Step title="Bridger 로그인 · 동의">
    커넥터를 추가하면 브라우저에서 Bridger 로그인과 권한 동의(OAuth)가 진행됩니다.
    Google 또는 GitHub로 로그인한 뒤 **Allow** 를 누르면 연결이 완료됩니다.
  </Step>

  <Step title="바로 사용하기">
    연결된 커넥터가 있는 상태로 한국 공공데이터를 자연어로 물어보세요.

    ```
    서울 강남구 오늘 날씨 어때?
    반포동 아파트 실거래가 알려줘
    서울 중구 미세먼지 상태 알려줘
    ```
  </Step>
</Steps>

## 더 많은 도구 켜기

연결 직후에는 클라이언트 성능을 위해 도구 목록이 기본 프로필 — `search_tools` + 자주 쓰는 도구 +
직접 켠 도구 — 로 제한됩니다. 목록에 없는 도구는 `search_tools`로 자연어 검색해 바로 호출할 수 있습니다.

- **대시보드에서 도구 켜기**: [대시보드](https://portal.bridger.kr)에서 원하는 공공데이터 API를 활성화하면
  다음 `tools/list`부터 기본 프로필에 항상 포함됩니다. 켜기/끄기 변경은 `notifications/tools/list_changed`
  알림으로 클라이언트에 즉시 전달됩니다.
- **전체 카탈로그 보기 (개발자용)**: MCP 엔드포인트 URL에 `?activation=all`을 붙이면 **{catalogTotal}**종의 공공데이터 도구를 포함한 전체 카탈로그를
  받을 수 있습니다. 예: `https://mcp.bridger.kr/mcp?activation=all`

## 문제 해결

<AccordionGroup>
  <Accordion title="Connectors 메뉴나 Add custom connector가 보이지 않아요">
    커스텀 커넥터는 플랜 · 리전에 따라 제공 범위가 다릅니다. 메뉴가 보이지 않으면
    계정의 플랜을 확인하거나, 대신 [Claude Code](/guides/claude-code) 또는
    [API 직접 연동](/guides/api)을 사용할 수 있습니다.
  </Accordion>
  <Accordion title="로그인 · 동의 화면이 나타나지 않아요">
    브라우저의 팝업 · 리디렉션 차단을 해제하고, URL이 `https://mcp.bridger.kr/mcp`로
    정확히 입력됐는지 확인하세요.
  </Accordion>
  <Accordion title="어떤 도구는 실행이 안 돼요">
    일부 공공데이터 API는 내 인증키(서비스키)가 필요합니다. [대시보드](https://portal.bridger.kr)에서
    해당 기관의 **내 인증키(서비스키)**를 등록하면 사용할 수 있습니다.
  </Accordion>
  <Accordion title="연결을 끊거나 다시 인증하고 싶어요">
    **Settings → Connectors** 에서 Bridger 커넥터를 열어 연결 해제(Disconnect)한 뒤
    다시 추가하면 재인증됩니다.
  </Accordion>
  <Accordion title="그래도 해결이 안 되면">
    [hello@bridger.kr](mailto:hello@bridger.kr) 또는 채널톡으로 문의해 주세요.
  </Accordion>
</AccordionGroup>
