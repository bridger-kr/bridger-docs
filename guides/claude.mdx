---
title: "Claude에 연결하기"
description: "Claude Desktop에서 Bridger MCP를 통해 한국 공공데이터를 바로 사용하는 방법 — 약 2분 소요."
---

Claude Desktop이 Bridger Gateway에 SSE로 연결되면, 230+ 공공데이터 도구를 별도 설치 없이
자연어로 사용할 수 있습니다.

<Steps>
  <Step title="Claude Desktop 설치">
    아직 Claude Desktop이 없다면 [Anthropic 공식 사이트](https://claude.ai/download)에서 다운로드하세요.
    macOS · Windows 모두 지원됩니다.
  </Step>

  <Step title="MCP 설정 파일 열기">
    Claude Desktop 메뉴에서 **Claude → Settings → Developer → Edit Config**를 클릭합니다.

    설정 파일 위치:

    <CodeGroup>
      ```text macOS
      ~/Library/Application Support/Claude/claude_desktop_config.json
      ```
      ```text Windows
      %APPDATA%\Claude\claude_desktop_config.json
      ```
    </CodeGroup>
  </Step>

  <Step title="Bridger MCP 서버 추가">
    설정 파일에 다음 내용을 추가합니다.

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "data-bridge": {
          "url": "https://mcp.datari.kr/mcp/sse",
          "headers": {
            "Authorization": "Bearer YOUR_API_KEY"
          }
        }
      }
    }
    ```

    <Tip>
      API 키는 [어드민 대시보드](https://admin.datari.kr)에서 계정 생성 후 발급받을 수 있습니다.
    </Tip>
  </Step>

  <Step title="Claude 재시작 후 사용">
    설정을 저장한 뒤 Claude Desktop을 완전히 종료하고 다시 실행하세요. 이제 한국 공공데이터를
    자연어로 바로 물어볼 수 있습니다.

    ```
    서울 강남구 오늘 날씨 어때?
    반포동 아파트 실거래가 알려줘
    삼성전자 주가 조회해줘
    ```
  </Step>
</Steps>

## 더 많은 도구 켜기

연결 직후에는 클라이언트 성능을 위해 도구 목록이 기본 프로필 — `datari.search_tools` + 자주 쓰는 도구 +
직접 켠 도구 — 로 제한됩니다. 목록에 없는 도구는 `datari.search_tools`로 자연어 검색해 바로 호출할 수 있습니다.

- **포털에서 도구 켜기**: [포털](https://portal.bridger.kr)에서 원하는 공공데이터 API를 활성화하면
  다음 `tools/list`부터 기본 프로필에 항상 포함됩니다. 켜기/끄기 변경은 `notifications/tools/list_changed`
  알림으로 클라이언트에 즉시 전달됩니다.
- **전체 카탈로그 보기 (개발자용)**: MCP 엔드포인트 URL에 `?activation=all`을 붙이면 230+ 전체 도구를
  받을 수 있습니다. 예: `https://mcp.bridger.kr/mcp?activation=all`

## 문제 해결

<AccordionGroup>
  <Accordion title="도구가 보이지 않아요">
    Claude Desktop을 완전히 종료한 뒤 다시 실행해 보세요. 설정 파일의 JSON 형식이
    올바른지(쉼표 · 따옴표 누락) 확인하세요.
  </Accordion>
  <Accordion title="인증 오류가 발생해요">
    API 키가 올바르게 입력되었는지 확인하고, 필요하면 [어드민 대시보드](https://admin.datari.kr)에서
    키를 재발급하세요.
  </Accordion>
  <Accordion title="그래도 해결이 안 되면">
    [이메일](mailto:support@datari.kr) 또는 채널톡으로 문의해 주세요.
  </Accordion>
</AccordionGroup>
