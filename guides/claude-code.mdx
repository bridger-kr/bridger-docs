title: "Claude Code에 연결하기"
description: "Claude Code CLI에서 한 줄 명령으로 Bridger MCP 서버를 추가하는 방법 — 약 1분 소요."
---

Claude Code에서는 `claude mcp add` 한 줄로 Bridger를 MCP 서버로 등록하고,
브라우저 OAuth로 인증합니다.

<Steps>
  <Step title="MCP 서버 추가">
    터미널에서 다음 명령을 실행합니다.

    ```bash
    claude mcp add --transport http bridger https://mcp.bridger.kr/mcp
    ```
  </Step>

  <Step title="OAuth 인증">
    `claude`를 실행한 뒤 `/mcp`를 입력하고 `bridger`를 선택합니다.
    **Authenticate**를 선택하면 브라우저가 열리고 Bridger 로그인(Google · GitHub)과
    권한 동의 화면이 나타납니다. **Allow**를 누르면 완료됩니다.
  </Step>

  <Step title="바로 사용하기">
    인증이 끝나면 Claude Code 세션에서 한국 공공데이터를 바로 요청할 수 있습니다.

    ```
    서울 강남구 내일 비 와?
    ```
  </Step>
</Steps>

## 문제 해결

<AccordionGroup>
  <Accordion title="인증이 풀리거나 만료됐어요">
    `/mcp`에서 `bridger`를 선택해 다시 **Authenticate**를 실행하면 재인증됩니다.
  </Accordion>
  <Accordion title="서버를 삭제하고 싶어요">
    ```bash
    claude mcp remove bridger
    ```
  </Accordion>
  <Accordion title="어떤 도구는 실행이 안 돼요">
    일부 공공데이터 API는 내 인증키(서비스키)가 필요합니다. [대시보드](https://portal.bridger.kr)에서
    해당 기관의 **내 인증키(서비스키)**를 등록하면 사용할 수 있습니다.
  </Accordion>
  <Accordion title="그래도 해결이 안 되면">
    [hello@bridger.kr](mailto:hello@bridger.kr) 또는 채널톡으로 문의해 주세요.
  </Accordion>
</AccordionGroup>
