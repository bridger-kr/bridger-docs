---
title: "ChatGPT에 연결하기"
description: "ChatGPT의 GPTs(Actions)로 Bridger를 호출하는 방법 — 약 2분 소요."
---

Bridger는 **원격 MCP 서버(Connector)** 로 ChatGPT에 연결됩니다. ChatGPT가 `https://mcp.datari.kr/mcp`에
직접 붙어, 230+ 한국 공공데이터 도구를 자연어로 사용할 수 있습니다. 인증은 OAuth로 처리됩니다.

<Note>
  원격 MCP 커넥터는 ChatGPT의 **개발자 모드(Developer Mode)** 또는 커넥터를 지원하는
  워크스페이스(Enterprise/Team 등)에서 사용할 수 있습니다.
</Note>

<Steps>
  <Step title="커넥터 추가">
    ChatGPT **Settings → Connectors → Add(또는 Developer Mode → MCP servers)** 에서
    원격 MCP 서버 URL로 다음을 입력합니다.

    ```text Remote MCP Server URL
    https://mcp.datari.kr/mcp
    ```

    전송 방식은 **Streamable HTTP**입니다.
  </Step>

  <Step title="OAuth 동의">
    커넥터를 추가하면 ChatGPT가 OAuth 인증을 시작합니다(Dynamic Client Registration + PKCE).
    Bridger 로그인 후 **동의(Allow)** 를 누르면 연결이 완료됩니다.

    <Tip>
      아직 계정이 없다면 [어드민 대시보드](https://admin.datari.kr)에서 먼저 계정을
      만드세요. 구글/카카오 소셜 로그인을 지원합니다.
    </Tip>
  </Step>

  <Step title="바로 사용하기">
    연결이 완료되면 ChatGPT에게 한국 데이터를 자연어로 물어볼 수 있습니다.

    ```
    서울 중구 미세먼지 상태 알려줘
    강남구 학동로 근처 약국 찾아줘
    오늘 달러 환율 얼마야?
    ```
  </Step>
</Steps>

## 더 많은 도구 켜기

연결 직후에는 클라이언트 성능을 위해 도구 목록이 기본 프로필 — `datari.search_tools` + 자주 쓰는 도구 +
직접 켠 도구 — 로 제한됩니다. 목록에 없는 도구는 `datari.search_tools`로 자연어 검색해 바로 호출할 수 있습니다.

- **포털에서 도구 켜기**: [포털](https://portal.bridger.kr)에서 원하는 공공데이터 API를 활성화하면
  다음 `tools/list`부터 기본 프로필에 항상 포함됩니다.
- **전체 카탈로그 보기 (개발자용)**: 커넥터 URL에 `?activation=all`을 붙이면 230+ 전체 도구를
  받을 수 있습니다. 예: `https://mcp.bridger.kr/mcp?activation=all`

## 문제 해결

<AccordionGroup>
  <Accordion title="커넥터 추가 메뉴가 보이지 않아요">
    원격 MCP 커넥터는 ChatGPT 개발자 모드 또는 커넥터를 지원하는 플랜에서만 노출됩니다.
    설정에서 개발자 모드를 활성화했는지 확인하세요.
  </Accordion>
  <Accordion title="OAuth 동의 화면이 나타나지 않아요">
    `https://mcp.datari.kr/mcp` URL이 정확한지, 브라우저 팝업/리디렉션이 차단되지 않았는지
    확인하세요.
  </Accordion>
  <Accordion title="데이터가 조회되지 않아요">
    일부 공공데이터 API는 야간에 점검될 수 있습니다. 잠시 후 다시 시도해 주세요.
  </Accordion>
  <Accordion title="그래도 해결이 안 되면">
    [이메일](mailto:support@datari.kr) 또는 채널톡으로 문의해 주세요.
  </Accordion>
</AccordionGroup>
