---

GPTs와 Actions를 사용할 수 있는 ChatGPT 워크스페이스에서는 DATA BRIDGE Gateway를 호출할 수 있습니다.

<Steps>
  <Step title="DATA BRIDGE GPT 접속">
    [DATA BRIDGE Korea GPT](https://chat.openai.com/g/mcphub-korea)를 엽니다.

  </Step>

  <Step title="계정 연결">
    GPT가 처음 한국 데이터를 조회할 때 DATA BRIDGE 계정 연결을 요청합니다. **"허용"**을
    클릭하면 자동으로 인증이 완료됩니다.

    <Tip>
      아직 계정이 없다면 [어드민 대시보드](https://admin.datari.kr)에서 계정을 먼저
      만드세요. 구글/카카오 소셜 로그인을 지원합니다.
    </Tip>
  </Step>

  <Step title="바로 사용하기">
    연결이 완료되면 ChatGPT에게 한국 데이터를 자연어로 물어볼 수 있습니다.

    ```
    서울 중구 미세먼지 상태 알려줘
    강남구 학동로 근처 약국 찾아줘
    오늘 달러 환율 얼마야?
    ```
  </Step>

  <Step title="(선택) 커스텀 GPT 만들기">
    자신만의 GPT에 DATA BRIDGE를 연동하고 싶다면 Actions에서 다음 OpenAPI 스펙을 임포트하세요.

    ```text OpenAPI Spec URL
    https://mcp.datari.kr/openapi.json
    ```

    GPT Builder에서 **Configure → Actions → Import from URL**로 위 URL을 입력합니다.
    인증 방식은 **API Key (Bearer Token)** 입니다.
  </Step>
</Steps>

## 문제 해결

<AccordionGroup>
  <Accordion title='"허용" 버튼이 나타나지 않아요'>
    GPT 설정의 Actions 인증 구성이 저장되어 있는지 확인하세요.
  </Accordion>
  <Accordion title="데이터가 조회되지 않아요">

  </Accordion>
  <Accordion title="그래도 해결이 안 되면">

  </Accordion>
