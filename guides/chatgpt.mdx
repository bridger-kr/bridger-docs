---
title: "ChatGPT에 연결하기"
description: "ChatGPT의 사용자 지정 앱(커넥터)으로 Bridger MCP를 연결하는 방법 — 약 3분 소요."
---

ChatGPT가 브릿저 게이트웨이(`https://mcp.bridger.kr/mcp`, Streamable HTTP)에 연결되면
한국 공공데이터 도구를 자연어로 바로 사용할 수 있습니다. 인증은 브릿저 계정
OAuth 로그인으로 진행됩니다.

<Note>
  사용자 지정 MCP 앱을 만들려면 **개발자 모드(Developer Mode)** 가 필요하며, 플랜에 따라
  조건이 다릅니다.

  - **Business**: 워크스페이스 관리자/소유자만 만들 수 있습니다. **Workspace settings →
    Apps → Create**에서 개발자 모드를 켜고 바로 앱을 만듭니다(관리자 각자가 직접 켜야 함).
  - **Enterprise/Edu**: 관리자가 **Permissions & Roles → Connected Data**에서 개발자 권한을
    부여하면(RBAC), 구성원이 **Settings → Apps → Advanced Settings → Developer mode**를 켭니다.
  - **Plus/Pro**: **Settings → Apps → Advanced settings → Developer mode**를 직접 켜서
    읽기 전용 커넥터를 연결할 수 있습니다.
  - Free/Go 플랜은 지원되지 않습니다.

  ChatGPT 앱 디렉터리 등록이 진행 중이며, 등록이 완료되면 디렉터리에서 바로 설치할 수 있습니다.
</Note>

<Steps>
  <Step title="개발자 모드 켜기">
    위 플랜 조건에 맞게 개발자 모드를 활성화합니다. 토글이 보이지 않으면 플랜 또는
    워크스페이스 권한을 먼저 확인하세요.
  </Step>

  <Step title="앱(커넥터) 만들기">
    **Settings → Apps → Create**(관리자는 Workspace settings → Apps → Create)에서
    MCP 서버 주소로 다음을 입력하고 인증 방식은 **OAuth**를 선택합니다.

    ```text Remote MCP Server URL
    https://mcp.bridger.kr/mcp
    ```

    전송 방식은 **Streamable HTTP**입니다. `/mcp/openai` 같은 다른 경로가 아니라
    반드시 `/mcp`를 입력하세요.
  </Step>

  <Step title="도구 스캔 + OAuth 로그인">
    **Scan Tools**를 누르면 ChatGPT가 서버를 검사하고 브릿저 로그인(OAuth) 화면을 엽니다.
    클라이언트 등록은 자동(DCR)이므로 client ID를 따로 입력할 필요가 없습니다.
    브릿저 계정으로 로그인하고 **승인(Allow)** 하면 스캔이 완료됩니다.

    <Tip>
      아직 계정이 없다면 [대시보드](https://portal.bridger.kr)에서 먼저 가입해 주세요.
      구글/깃허브 소셜 로그인을 지원합니다.
    </Tip>
  </Step>

  <Step title="만들기 완료 후 사용">
    스캔이 끝나면 **Create**를 누르세요. 새 앱은 Settings → Apps의 Enabled Apps에
    **Dev** 라벨로 표시됩니다. 새 대화에서 앱을 선택한 뒤 한국 데이터를 자연어로 물어보세요.

    ```
    서울 강남구 내일 날씨 어때?
    지금 서울 미세먼지 상태 알려줘
    반포동 아파트 실거래가 알려줘
    ```

    <Note>
      아파트 실거래가처럼 공공데이터포털 키가 필요한 도구는, 계정에 키가 없으면
      데이터 대신 **내 인증키(서비스키) 등록 안내**를 돌려줍니다. [대시보드](https://portal.bridger.kr)에서
      내 인증키(서비스키)를 등록하면 바로 조회됩니다.
    </Note>
  </Step>
</Steps>

## 더 많은 도구 켜기

연결 직후에는 클라이언트 성능을 위해 도구 목록이 기본 프로필 — `search_tools` + 자주 쓰는 도구 +
직접 켠 도구 — 로 제한됩니다. 목록에 없는 도구는 `search_tools`로 자연어 검색해 바로 호출할 수 있습니다.

- **대시보드에서 도구 켜기**: [대시보드](https://portal.bridger.kr)에서 원하는 공공데이터 API를 활성화하면
  다음 `tools/list`부터 기본 프로필에 항상 포함됩니다.
- **전체 카탈로그 보기 (개발자용)**: 커넥터 URL에 `?activation=all`을 붙이면 {{catalogTotal}}종의 공공데이터 도구를 포함한 전체 카탈로그를
  받을 수 있습니다. 예: `https://mcp.bridger.kr/mcp?activation=all`

## 문제 해결

<AccordionGroup>
  <Accordion title="개발자 모드 토글 / Create 버튼이 보이지 않아요">
    플랜이 개발자 모드를 지원하는지 확인하세요. Business는 관리자/소유자만,
    Enterprise/Edu는 관리자가 RBAC로 권한을 부여해야 합니다.
  </Accordion>
  <Accordion title="Scan Tools가 실패해요">
    `https://mcp.bridger.kr/mcp` URL이 정확한지 확인하세요. 끝에 `/openai` 등
    경로를 붙이면 안 됩니다. 브라우저 팝업/리디렉션이 차단됐는지도 확인하세요.
  </Accordion>
  <Accordion title="로그인 후 다시 로그인하라고 해요">
    OAuth 토큰 갱신 설정 문제일 수 있습니다. 잠시 후 재시도하고, 계속되면
    커넥터를 지우고 다시 만들어 보세요.
  </Accordion>
  <Accordion title="데이터가 조회되지 않아요">
    일부 공공데이터 API는 야간에 점검될 수 있습니다. 잠시 후 다시 시도해 주세요.
  </Accordion>
  <Accordion title="그래도 해결이 안 되면">
    [hello@bridger.kr](mailto:hello@bridger.kr)로 문의해 주세요.
  </Accordion>
</AccordionGroup>
