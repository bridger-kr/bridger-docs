<Warning>
  이 레거시 엔드포인트는 테넌트 범위가 아닌 빈 컬렉션을 의도적으로 반환합니다. 로드된 프리셋이나 테넌트의 도구를 노출하지 않습니다. 빈 응답은 정상 동작이며, 사용 가능한 프리셋이 없다는 뜻이 아닙니다.
</Warning>

도구를 조회하려면 Bridger API 키로 `POST https://mcp.bridger.kr/mcp?activation=all`에 `tools/list`를 보내세요. `activation=all`을 생략하면 기본 도구 프로필을 반환합니다.

[도구 조회 및 요청 예시](/api-reference/mcp-jsonrpc#toolslist)

## Request

```http
GET https://api.bridger.kr/registry/tools
```

인증은 필요하지 않습니다. 이 경로는 `api.bridger.kr`에서 제공하며, `mcp.bridger.kr/registry/tools`는 404를 반환합니다.

## Response 200

```json
{"tools": [], "total": 0}
```
