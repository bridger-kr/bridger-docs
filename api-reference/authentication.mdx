datari Gateway는 두 가지 인증 헤더를 받습니다. 둘 중 하나만 보내면 됩니다.

```http
x-api-key: dat_live_xxx
Authorization: Bearer dat_live_xxx
```

## API Key 발급

[admin.datari.kr](https://admin.datari.kr) → **Settings → API Keys**에서 발급/회수합니다.
자세한 흐름은 [구독 가이드](/guides/subscribe)를 참고하세요.

## 인증 실패 응답

키가 없거나 잘못된 경우 **401 Unauthorized**가 반환됩니다.

```json
{
  "error": "Unauthorized",
  "message": "Valid API key is required."
}
```

## 테넌트 식별

엔터프라이즈 플랜에서는 `x-tenant-id` 헤더 또는 API Key 자체로 테넌트가 식별됩니다.
테넌트별 독립 Rate Limit이 적용됩니다.

```http
x-api-key: tenant-a-key
x-tenant-id: tenant-a
```

`TENANT_CONFIG_JSON` 환경변수로 테넌트별 설정을 구성합니다.

```json
{
  "tenant-a": { "apiKey": "key-a", "rateLimitPerMin": 200 },
  "tenant-b": { "apiKey": "key-b", "rateLimitPerMin": 60 }
}
```

## OAuth 2.0

조직 단위 권한 관리·SSO 연동이 필요한 경우 OAuth 2.0 Authorization Code 또는
Client Credentials 흐름을 사용합니다.

<Note>
  OAuth 클라이언트 등록은 현재 베타이며, [admin.datari.kr](https://admin.datari.kr)에서
  요청할 수 있습니다. 발급 후 access token을 동일하게 `Authorization: Bearer ...` 헤더로 전달하면 됩니다.
</Note>

## cURL 예시

```bash
curl -X POST https://mcp.datari.kr/mcp \
  -H "x-api-key: $DATARI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
