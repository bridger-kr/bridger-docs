---
title: "첫 도구 호출"
description: "MCP 도구를 처음 호출해 봅니다."
---

<Note>이 페이지는 Phase 2에서 채워집니다.</Note>

`tools/list`로 사용 가능한 도구를 확인하고, `tools/call`로 첫 도구를 실행합니다.

```bash
curl -X POST https://mcp.datari.kr/mcp \
  -H "x-api-key: $DATARI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
