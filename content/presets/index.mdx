## 빠른 사용

```bash
# 전체 목록 확인
mcp-gen list

# 카테고리별 필터
mcp-gen list --category weather

# 키워드 검색
mcp-gen search 날씨

# 카테고리 단위 설치
mcp-gen install weather
```

<Note>
  이 페이지는 `apps/docs/scripts/build-presets.mjs`가 `presets/**/*.yaml`을
  스캔하여 자동 생성합니다. 직접 수정하지 마세요.
</Note>
