  특정 도구만 사용하고 싶다면 `mcp-gen install environment/<preset-name>` 형식으로 개별 설치할 수 있습니다.

</Tip>

## 사용 예시

<CodeGroup>
  ```bash mcp-gen
  # 카테고리 전체 설치
  mcp-gen install environment

  # 특정 프리셋만 설치
  mcp-gen install environment/<preset-name>
  ```

  ```bash 호스팅 Gateway
  curl -X POST https://mcp.datari.kr/mcp \
    -H "x-api-key: $DATARI_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | jq '.result.tools[] | select(.name | startswith("@mcphub/environment-"))'
  ```
</CodeGroup>

<Note>
  이 페이지는 `apps/docs/scripts/build-presets.mjs`가 `presets/environment/*.yaml`을
  스캔하여 자동 생성합니다. 직접 수정하지 마세요.
</Note>
